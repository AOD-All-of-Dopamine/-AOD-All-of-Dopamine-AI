# W-6 사전등록 — 웹소설 **제품 경로 `next_page`** 의 시드 에코·페이지 간 판본 재등장 (2026-09-15)

## 왜 — W-5 채택 직후 스모크에서 나왔다 (채점 없음)
W-5 는 평가 경로(`wn_eval.Engine.recommend`)의 에코·판본 중복을 0 으로 만들었다. 같은 설정으로 **실제 새로고침 제품 경로** `personalized_retrieve.next_page`
(52프로필 × 3페이지 × 10편, seen 누적)를 재니 남아 있었다:

| `next_page` 1~3페이지 | series_by=publisher (W-5 전) | series_by=author (현행) |
|---|---|---|
| 시드 에코 (정규화 제목+작가가 시드와 같음) | 33 (전부 1페이지) | **33** (전부 1페이지) |
| 페이지 안 판본 중복 | 12 | 0 |
| **이전 페이지에 나온 작품의 판본이 다음 페이지에 재등장** | 59 | **72** |
| 1페이지 == Engine top-10 | 28/52 | 25/52 |

예: `coh_hunter` 1페이지 *튜토리얼이 너무 어렵다* · `coh_regression` *회귀의 전설* · `coh_murim` *절대 검감(絶對 劍感)* · `coh_bl_marriage` *메리지 어게인*.

### 원인 (코드 확인)
- `run_multi(postprocess=True)` 는 `postprocess()`(hard filter → `cap_series` → `cap_author` → 인터리빙)만 부른다. **`drop_seed_series` 를 부르지 않는다.**
  (§71 X-20 에서 이 경로의 "죽은 줄"을 정리했다는 기록이 있다.) 그래서 시드 판본이 1페이지에 뜬다.
- 제외는 `exclude_ids = liked ∪ seen` 을 **작품 id 로만** 뺀다. `cap_series` 는 호출 한 번(한 페이지) 안에서만 작동한다.
  그래서 1페이지에서 본 작품의 다른 판본이 2·3페이지에 다시 나온다. W-5 로 페이지 안 중복을 없애자 그만큼이 페이지 간으로 밀려 59→72 가 됐다.

## 가설 H-W6
> 제품 경로의 시드 에코·페이지 간 판본 재등장은 제외 집합을 id 로만 빼기 때문이다.
> 제외 집합(시드 ∪ seen)의 **시리즈 키**(`series_group`, 현행 작가 키)에 속하는 후보를 후처리 전에 빼면 셋 다 0 이 되고, 들어온 작품은 원래 페이지의 뒤쪽 작품만큼 적합하다.

반증 조건: (i) 빼도 에코·재등장이 남는다 → 원인 진단이 틀렸다. (ii) 들어온 작품이 대조보다 뚜렷이 덜 적합하다.

## 변형 — 팔 2개
| 팔 | `drop_excluded_series` | 비고 |
|---|---|---|
| **n0** | False | **현행 제품 경로** |
| **n1** | True | `run_multi` 가 후처리 전에 `drop_seed_series(ranked, dataset, liked ∪ seen)` |

- 구현: `run_multi(..., drop_excluded_series=None)` · `next_page` 가 그대로 넘긴다. `None` = `PRODUCTION["drop_excluded_series"]` = **False**(판정 전 제품 불변).
- 다른 축 전부 PRODUCTION(top2_mean · pop 0 · series_by author · min_interest None). 평가 경로 `Engine.recommend` 는 건드리지 않는다.
- **빌드 assert**: n0 이 이 사전등록 직전 측정(에코 33 · 재등장 72 · 페이지 안 0)을 그대로 재현한다.

## 판정 1 — 기계 (주, 채점 없음)
52프로필 · `next_page(page_size=10)` 3회 · seen 누적 · n1:
- **에코** = 시드와 (정규화 제목, 작가) 가 같은 표시 작품 수 → **0**
- **페이지 안 중복** = 한 페이지에서 (제목, 작가) 가 두 번째 이상 → **0**
- **페이지 간 재등장** = 이전 페이지에 나온 (제목, 작가) 가 다시 나온 수 → **0**

## 판정 2 — 채점 가드
- **E (진입)** = n1 1~3페이지에 있고 n0 1~3페이지에 없는 (프로필, 작품) — 전수
- **Ctl (대조)** = n0·n1 둘 다에 있고 n1 **3페이지** 에 있는 (프로필, 작품) 중 프로필마다 그 프로필의 |E| 개 무작위(모자라면 전부) · **RNG seed 61**
- **Lv (이탈, 부수)** = n0 에 있고 n1 에 없는 — 전수
- 세 집합을 한 시트에 섞어 3역할 새로 채점. 시트 meta·역할 프롬프트는 W-5 와 같다(`eval/w1_preregister.md` md5 cdaeb8e8496f869ef87273d3c057e880 원문).
- W-5 채점 재사용 없음(W-5 는 k=50 평가 경로 목록이라 쌍이 달라도 섞지 않는다).

`Δ_guard = 다수결적합(E) − 다수결적합(Ctl)` (적합 = 3역할 중 2 이상 등급 ≥ 2).

## 판정 (관측 전 고정)
- **(A) 채택** — 기계 0/0/0 · `Δ_guard ≥ −0.10` → `PRODUCTION["drop_excluded_series"] = True`
- **(B) 보류** — 기계 통과 · `−0.20 ≤ Δ_guard < −0.10` → 현행 유지, 시드만 빼고 seen 은 빼지 않는 좁은 규칙을 다음 라운드로
- **(C) 기각** — 기계 실패 또는 `Δ_guard < −0.20` → 현행 유지

마진 근거는 W-5 와 같다(결함 수정의 비열등 가드).

### 부수 관측 (판정 아님)
