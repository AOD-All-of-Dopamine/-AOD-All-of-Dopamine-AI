# W-5 사전등록 — 웹소설 **같은 작품 판본 중복** (시리즈 키: 출판사 → 작가) (2026-09-15)

## 왜 — '실제 서비스 느낌' 기계 감사에서 나왔다 (채점 없음)
네 플랫폼 현행 서빙 top-10/50 을 기계적으로 점검했다(시드 시리즈 누수 · 목록 내 중복 · 허브 · 인기 · 성인물 · 연식).
웹소설에서 **실제 서비스라면 절대 안 보일 것**이 나왔다 — 좋아한 작품과 **제목·작가가 똑같은 작품**이 추천되고,
한 목록에 **같은 작품이 두 번** 나온다.

| 현행 서빙 (wn_v6 · PRODUCTION · 52프로필 · `w4_lists` a0 = 서빙 목록) | @10 | @50 |
|---|---|---|
| 시드와 정규화 제목이 같은 추천 (시드 에코) | **11** | 11 |
| 목록 내 같은 제목 추가 중복 | **5** | **32** |
| 에코·중복이 top-10 에 있는 프로필 | **14/52** | — |

예: `coh_hunter` 시드 *튜토리얼이 너무 어렵다* → 추천에 *튜토리얼이 너무 어렵다* · `coh_modern_success` top-10 에 *재벌집 천재가 되었다* 두 번.

### 원인 (코드·코퍼스 확인)
- 두 항목은 네이버 시리즈의 **다른 productNo** 다 — 같은 작가, 한쪽은 연재본(259화·관심 242만), 한쪽은 짧은 판본(11화·관심 9천).
- `postprocess.series_group(name, publisher)` = `출판사|제목 첫 어절`. docstring 전제는 "같은 작품의 판본은 같은 출판사에서 나온다".
- **wn_v6 에서는 전제가 깨진다** — 판본마다 출판사 표기가 다르다: `제이플미디어` / `제이플러스`, `북큐브(북큐브 제공)` / `북큐브`, `마루&마야` / `마야마루출판사`, `보헤미안` / `나이트게일`.
- 코퍼스: 정규화 제목이 2개 이상인 제목 **2,182개**(항목 4,382) · 그중 작가 1명 **2,109** · 작가 여럿 73. 같은 제목+작가인데 출판사 키가 갈리는 묶음 **292**.
- 그래서 `drop_seed_series`(시드 판본 제거)와 `cap_series`(시리즈당 1편)가 둘 다 이 판본을 **다른 시리즈로 본다.**

## 가설 H-W5
> 웹소설 시드 에코·목록 내 판본 중복은 시리즈 키가 출판사 표기에 의존하기 때문이다.
> 키를 `작가|series_key(제목)` 으로 바꾸면 에코·중복이 0 이 되고, 빈자리를 채운 작품은 원래 목록의 꼬리 작품만큼 적합하다.

반증 조건: (i) 키를 바꿔도 에코·중복이 남는다 → 원인 진단이 틀렸다. (ii) 들어온 작품이 대조군보다 뚜렷이 덜 적합하다 → 중복 제거의 품질 비용이 크다.

## 변형 — 팔 2개
| 팔 | 시리즈 키 | 비고 |
|---|---|---|
| **s0** | `출판사|첫 어절` (작가 무시) | **현행 서빙** |
| **s1** | `작가|series_key(제목 앞 2어절)` · 작가 없으면 기존 키 | 후보 |

- 구현: `series_group(..., author, by)` · `drop_seed_series`/`cap_series`/`postprocess`/`Engine.recommend` 에 `series_by` 를 흘린다. `None` = `PRODUCTION["series_by"]` = `"publisher"`(판정 전 서빙 불변).
- 다른 축 전부 PRODUCTION(top2_mean · pop 0 · rating 0 · hub 0 · mmr 1.0 · author_w 0 · series 1 · author 2).
- **빌드 assert**: s0 목록이 `eval/w4_lists.json` a0 과 52/52 완전 일치.
- 작가 앞 2어절 키가 **다른 작품을 묶는** 경우(같은 작가의 `검은머리 미 FBI 특수요원` / `검은머리 미 CIA 요원` 같은 연작)는 기존 규칙("좋아한 작품의 외전·2부 재추천은 중복", 2026-08-22 사용자 피드백)과 같은 취급이다. 빌드에서 **제목이 다른데 빠진 작품** 수와 목록을 부수로 전부 적는다.

## 판정 1 — 기계 (주, 채점 없음)
정규화 제목 = 소문자 · 공백/기호 제거. 52프로필 · k=50 · s1:
- **M-echo** = 추천 중 (정규화 제목, 작가) 가 시드 중 하나와 같은 항목 수 → **0 이어야 한다**
- **M-dup** = 한 목록에서 (정규화 제목, 작가) 가 이미 나온 항목 수 → **0 이어야 한다**

## 판정 2 — 채점 가드 (들어온 작품이 나쁘지 않은가)
**일반 P@50 비교는 쓰지 않는다.** 에코는 채점자에게 "시드와 똑같다 = 강한 적합"으로 보일 것이고(D-32 · X-25: 이 잣대는 중복을 보상한다),
중복을 빼는 변경은 정의상 슬롯 적합률이 불리하게 나온다. 그래서 **들어온 작품만** 따로 잰다.

- **E (진입)** = s1 top-50 에 있고 s0 top-50 에 없는 (프로필, 작품) — **전수**
- **Ctl (대조)** = s0·s1 둘 다에 있고 s1 순위 31~50 인 (프로필, 작품) 중 프로필마다 그 프로필의 |E| 개 무작위(모자라면 전부) · **RNG seed 51**
- **Lv (이탈, 부수)** = s0 top-50 에 있고 s1 top-50 에 없는 (프로필, 작품) — 전수
- 세 집합을 **한 시트에 섞어** 3역할 새로 채점(은행 재사용 없음, 시트에 집합 표시 없음). 시트 meta 는 W-4 와 동일(장르·화수·줄거리 70자 · 작가/관심수/평점 없음).
- 역할 프롬프트는 `eval/w1_preregister.md`(md5 cdaeb8e8496f869ef87273d3c057e880) 원문(W-4 사전등록에 전재한 그대로).

적합 = 3역할 중 2역할 이상 등급 ≥ 2. `Δ_guard = 다수결적합(E) − 다수결적합(Ctl)`.

## 판정 (관측 전 고정 — 이후 움직이지 않는다)
- **(A) 채택** — M-echo = 0 · M-dup = 0 · `Δ_guard ≥ −0.10` → `PRODUCTION["series_by"] = "author"`
- **(B) 보류** — 기계 통과 · `−0.20 ≤ Δ_guard < −0.10` → 현행 유지, 다음 라운드는 **제목+작가 완전 일치만** 묶는 좁은 규칙
- **(C) 기각** — 기계 실패(원인 진단 틀림) 또는 `Δ_guard < −0.20` → 현행 유지

마진 −0.10 의 근거: 이것은 결함 수정이지 새 신호 채택이 아니다(에코는 발견이 아니다). |E| 가 60~90 이면 비율 표준오차가 약 0.05 라, 가드는 "뚜렷이 나쁜 대체"만 막는다. 관측 후 마진을 바꾸지 않는다.

### 부수 관측 (판정 아님)
|E| · |Lv| · 이탈 중 에코/중복 비율 · 제목이 다른데 빠진 작품 목록 · E 의 1-10/11-50 적합 · Lv 다수결 적합(에코를 채점자가 얼마나 보상하는지) · 역할별 · ILS@50 · 에코가 있던 14프로필의 top-10 전후.

## 예상 (관측 전)
**(A).** 기계 0/0. |E| 50~90. `Δ_guard` −0.05 ~ +0.05. **Lv 다수결 적합 ≥ 0.90** — 에코·판본은 채점자에게 거의 만점일 것이고,
이것이 "P@k 로는 이 결함을 못 본다"는 기록이 된다.
