## v4 에 있던 1,724편이 v6 에 없다 — **결함이 아니라 교정이다**
전부 **미리보기판**이다. 네이버 시리즈는 한 작품을 미리보기(3~13화)와 본편(95~328화) 두 상품으로 올린다.
파일럿 코퍼스에는 본편이 안 들어와서 **미리보기가 그 작품의 대표로 남아 있었다.** 전체 코퍼스에는 둘 다 있고,
`drop_preview_editions`(제목·출판사·줄거리 동일, 화수 많은 쪽 채택)가 본편을 골랐다.

단계별 실측: 원본 41,415 → 행 통과 41,028(사라진 것 1,706 생존) → item_id dedup 41,028(1,706 생존)
→ **미리보기 dedup 29,263 (1,706 → 0 생존)**. 탈락 지점이 한 곳에 모인다.

예: `무림학원의 천재 마법사가 되었다` — 미리보기 id 10289154 (10화 · 관심 2,600) vs 본편 id 9241758 (250화 · 관심 102만).
