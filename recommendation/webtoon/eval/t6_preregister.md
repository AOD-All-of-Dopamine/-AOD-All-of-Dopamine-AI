# T-6 사전등록 — 웹툰 `star_boost` (평점 백분위 배율) (2026-09-04) — 마지막 축

## 왜
`star_boost` 는 `final = sim × (1 + star_boost × star_pct)`, `star_pct` 는 평점의 코퍼스 백분위다.
웹소설은 같은 자리에서 **품질 신호가 없다**고 확정했다(D-62). 웹툰도 그럴 가능성이 높다 — 관측 전 사전 점검(판정 아님):
- 평점 분포가 극도로 압축돼 있다: 중앙 9.89 · p5 8.94 · p95 9.97 (10점 만점). 백분위로 쓰니 압축 자체는 문제가 아니지만,
  차이가 잡음 수준이면 백분위도 잡음이다.
- 은행 3,987쌍에서 corr(평점 백분위, 적합) = **+0.004**, 5분위 적합률 0.769 / 0.775 / 0.778 / 0.745 / 0.776 — 평평하다.
- corr(평점, log 관심수) = 0.311 — 평점은 인기와 약하게 얽혀 있어서 배율을 키우면 T-2 의 인기 배율과 비슷하게 움직일 수 있다.
그래도 잰다. 이식값·사전 점검 대신 **측정된 0** 으로 마무리하는 것이 이 플랫폼의 원칙이다.

## 판정 (관측 전 고정) — 합산 기준
- **(A) 채택**: b10 또는 b20 이 b0 대비 **≥ +0.03** → 더 높은 쪽 (동률이면 작은 값)
- **(C) 0 유지**: 둘 다 **< +0.02**
- 사이 → **보류**, 0 유지
- **(E) 다양성 안전장치**: 채택 후보의 ILS@50 이 b0 보다 **+0.03 이상 높으면** 채택하지 않는다.
- **(F) 혼합 안전장치**: 채택 후보의 `mix` 12프로필 합산이 b0 보다 **0.05 이상 낮으면** 채택하지 않는다.
- 부수 관측(판정 아님): top-50 관심수 중앙 — 평점 배율이 인기 배율의 대역인지 확인한다.

## 예상
