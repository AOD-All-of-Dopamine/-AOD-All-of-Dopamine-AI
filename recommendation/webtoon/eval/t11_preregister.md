# T-11 사전등록 — 웹툰 **싫어요 유사 감점** (`dislike_w`) (2026-09-15)

## 왜 — 싫어요가 다음 추천에 반영되지 않는다
제품 요구: 좋아요·싫어요가 바뀌면 다음 추천에 바로 반영돼야 한다.
기계 측정(채점 없음, 67프로필, `feedback_probe`): 좋아요 추가·취소는 즉시 반영된다. 싫어요는 **반영되지 않는다** —
웹툰에는 싫어요 인자가 없어 제외 목록에 넣는 것이 전부였다.
- 본 카드(1페이지 1위) 싫어요 → 다음 20개가 그대로인 비율 **1.00**, 싫어요 작품의 최근접 50 중 다음 20개 속 **5.79 → 5.79**
- 안 본 작품 싫어요 → 닮은 작품 3.88 → 4.34 (빈자리를 닮은 작품이 채워 오히려 늘어난다)
- Steam 은 감점(`w=2.0 · floor 0.45`, 미채점)이 있어 1.08 → 0.06.

제품 결정(사용자, 2026-09-15): 싫어요 신호는 `content_likes` 의 **DISLIKE 만** · 싫어요한 작품의 **같은 시리즈도 뺀다** ·
웹툰부터 시작해 웹소설 → TMDB → Steam 감점 검증 순서.

## 단계 1 — 임계값 (채점 없음, `src/t11_floor.py` → `eval/t11_floor.json`)
규칙(측정 전 고정): **floor = 무관 싫어요 유사도 p99 를 0.01 단위 올림.**
- 무관 U(장르가 다른 다음 프로필의 1위, 풀 100): p50 0.435 · p95 0.549 · **p99 0.600** · 최대 0.694
- 표적 T(1위의 최근접 50 ∩ 풀 100): p10 0.569 · p25 0.592 · p50 0.619
- → **floor 0.61.** T 의 58% · U 의 0.7% 가 floor 이상. 무관 싫어요가 풀 100 중 1개라도 건드리는 프로필 19%.
- Steam(무관 최대 0.415 < 표적 0.46)과 달리 **두 분포가 겹친다** — 무관 가드를 판정 조건에 넣는 이유.
- 크기: 풀 1위−20위 접힌 유사도 간격 중앙 0.036 · floor 초과분 중앙 0.034 → w=1/2/3 감점 중앙 = 간격의 0.95/1.91/2.86배.

## 가설 H-T11
> 접힌 점수에서 `w × Σ_i max(0, sim(후보, 싫어요_i) − 0.61)` 를 빼면, 싫어요한 작품과 닮은 작품이 다음 목록에서 줄고
> 무관한 싫어요는 목록을 흔들지 않으며, 좋아요 기준 적합률은 허용폭 안에서 유지된다.

반증 조건: 닮은 작품이 절반 이상 줄지 않는다(임계가 너무 높다) · 무관 싫어요가 목록을 흔든다(분포 겹침) · 적합률이 −0.05 보다 더 떨어진다.

## 구현 (이 사전등록과 같은 커밋)
- `Engine.recommend(disliked_ids, dislike_w, dislike_floor)` — `folded` 직후 감점. 좋아요와 같은 `similarity`(허브 보정 PRODUCTION=0.0).
  싫어요 작품은 항상 제외, **같은 시리즈(`series_key`)도 제외** — 모든 팔 공통(제품 결정, 판정 대상 아님). `next_page(**kw)` 로 전달.
- `PRODUCTION["dislike_w"] = 0.0`(판정 전 끔) · `dislike_floor = 0.61`.
- 회귀: 싫어요 없는 기본 경로 5페이지 전부 == T-10 n0 **67/67**. 계약 테스트 `tests/test_dislike.py` 5개 통과
  (제외 · 시리즈 제외 · 무싫어요 불변 · 임계 1.01 이면 무변화 · 표적 감소).
- 알려진 한계: `series_key` 는 제목 끝에 숫자가 붙은 속편을 못 묶는다(코퍼스 16쌍).

## 시나리오 (규칙 고정 · 프로필 67 전부)
- `page1 = next_page(seeds, k=10, seen=[])` — 싫어요 없음. **빌드 assert**: page1 == T-10 n0 1페이지 67/67.
- **표적**: `d = page1[0]` → `page2 = next_page(seeds, k=20, seen=page1, disliked_ids=[d], dislike_w=w)`
- **무관**: `du` = 프로필 순서상 다음(순환)이면서 장르가 다르고 그 1위가 이 프로필의 page1 ∪ 시드 ∪ 풀100(`recommend k=100, exclude=page1`)에 없는 프로필의 page1[0]
  → `page2u = next_page(seeds, k=20, seen=page1, disliked_ids=[du], dislike_w=w)`
- 닮은 작품 `NN50(d)` = 정규화 임베딩 내적 상위 50 (d 자신 제외).
- 빌드 assert: 모든 page2·page2u 길이 20.

## 채점
표적 시나리오에서 **팔마다 page2(팔) 와 page2(d0) 가 다른 작품만** 채점한다 — 들어온 작품(팔에만) · 빠진 작품(d0 에만).
겹치는 작품은 두 쪽에 같게 들어가 차이에 기여하지 않는다. (프로필, 작품) 쌍은 팔을 넘어 한 번만 채점.
3역할 새로 채점 · 은행 재사용 없음 · 섞은 한 시트(RNG seed 11) · 60건 배치.
역할 프롬프트 `eval/t1_preregister.md`(md5 2f06edaa5549fac17941f79dcebe85e4) **원문**. 시트 seed = 좋아요 시드 이름만(싫어요는 넣지 않는다), meta 는 T-10 과 같다(장르 · 태그 6 · 회차).

## 판정 (관측 전 고정 — 이후 움직이지 않는다)
적합 = 3역할 중 2역할 이상 등급 ≥ 2.

    (나) 반영   N(팔) = 프로필 평균 |page2(팔) ∩ NN50(d)|          통과: N(팔) ≤ 0.5 × N(d0)
    무관 가드   O(팔) = 프로필 평균 |page2u(팔) ∩ page2u(d0)| / 20   통과: O(팔) ≥ 0.95
    (가) 품질   Δ(팔) = Σ_프로필 (적합 들어온 수 − 적합 빠진 수) / (67 × 20)   통과: Δ(팔) ≥ −0.05

- **(A) 채택** — 세 조건을 모두 통과한 팔 중 **가장 작은 w** → `PRODUCTION["dislike_w"] = w`
- **(C) 기각** — 통과한 팔 없음 → `dislike_w = 0.0` 유지 (싫어요 작품·시리즈 제외만)
- 미채점 0 전에는 판정하지 않는다.

품질 문턱 −0.05 의 근거: 채점자는 좋아요만 보고 판단하므로 싫어요와 닮은 작품(= 좋아요 시드와도 닮은 작품)이 빠지면
적합률이 조금 떨어지는 것이 설계상 예상된 비용이다(Steam 싫어요 설계 기록: w=2 에서 P@30 −0.06).
±0.03~0.05 가 이 잣대의 단일 라운드 잡음 폭(§94~§96)이라 그 이상 떨어지는 것만 손해로 본다.

### 부수 관측 (판정 아님)
팔별 역할 A/B/C Δ · 축(rule/coh/mix/count)별 N·Δ · 들어온/빠진 작품 수 · 무관 가드 프로필 분포 · page2 에서 싫어요 작품과 같은 dominant 시드 비율.
