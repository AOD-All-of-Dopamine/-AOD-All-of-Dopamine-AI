# 웹툰 추천 (webtoon)

네이버 웹툰 정식 연재/완결 작품 대상 오프라인 배치 추천 파이프라인.
`webnovel/` 의 구조를 이식하고 도메인 술어만 교체했다. 네 번째 단일 플랫폼이다.

```
크롤 → 정제 → 표현 → 임베딩 → [표현 진단 게이트] → 검색·랭킹 → 후처리 → 판정
```

---

## 1. 자료원 — 왜 네이버 웹툰인가

`comic.naver.com` 의 **공개 JSON API**. 로그인·키 없이 열리고 HTML 파싱이 필요 없다.

| 항목 | 값 (2026-09-04 실측) |
|---|---|
| 연재 중 | 752편 (요일별 목록 7개, 중복 제거) |
| 완결 | 3,116편 (70페이지) |
| **고유 합계** | **3,868편** |

**도전만화·베스트도전은 넣지 않는다.** 정식 연재가 아니고 품질 분포가 완전히 달라
같은 코퍼스에 섞으면 랭킹이 무너진다(Steam 이 리뷰 미보고 롱테일에서 겪은 문제와 같은 모양).

**성인 웹툰은 상세 API 가 401 을 준다** — 웹소설 19금이 로그인 리다이렉트로 빠지던 것과 같다.
따로 거를 필요 없이 수집 단계에서 빠지고, `postprocess` 에서 한 번 더 막는다.

대안으로 검토한 **네이버 시리즈 "만화"** 는 단행본 만화 중심이라 "웹툰"이 아니고,
크롤 구조도 웹소설 판과 겹쳐 새로 얻는 것이 적다. 그래서 쓰지 않았다.

## 2. 웹소설 판과 무엇이 같고 무엇이 다른가

**같은 것** — 계약과 규율. 시드별 질의(평균 내지 않음) → 접기 → `유사도 × (1+보정)` 정렬 →
후처리(하드 필터 → 시리즈 상한 → 작가 상한 → 시드 교차 → Top-N) → `next_page()` 제외 집합,
그리고 **사전등록 → md5 봉인 → 눈가림 3역할 채점 → 미채점 0 → 판정**.

**다른 것** — 신호.

| | 웹소설 | 웹툰 |
|---|---|---|
| 인기도 | `interest_count` | **`favorite_count`** (관심 수) |
| 평점 | `rating` (신호 없었음 D-62) | **`star_score`** (10점, 미측정) |
| 장르 | 1개 coarse 라벨 | 1~2개 + **`tags` 10~12개** |
| 작가 | `author` 1명 | **글/그림 분리** (`artists`) |
| 연령 | `age_limit` 19 | `age_type` RATE_19 · `adult` |
| 시리즈 마커 | n부 · 외전 · 시즌n · [단행본] | 시즌n · n부 · 외전 · [리메이크] |
| 원작 링크 | 없음 | **`novelOriginAuthors`** (웹소설 원작 표시) |

**가장 큰 차이는 태그다.** 작품당 10~12개(`사이다`·`먼치킨`·`학원물`·`다크히어로`·`소설원작`…)로
Steam 태그에 가까운 밀도다. 그래서 두 곳에서 기회가 된다 —
표현(`semantic_text` 에 태그를 넣을지)과 정렬(Steam 의 태그 피복률 `tag_w` 형태).
**둘 다 아직 측정하지 않았다.**

## 3. 확정된 값 — **아직 없다**

`src/config.py` 의 `PRODUCTION` 은 전부 **웹소설에서 이식한 출발점**이고 웹툰에서 측정된 적이 없다.
값 옆에 D-번호가 없다는 것이 그 뜻이다. 순서는 이렇게 간다:

1. **표현 진단 게이트** (`src.diagnose_representation`) — 장르 변별력·유사도 평탄도·허브.
   rep_v1(제목+장르+줄거리) vs rep_v2(+태그)를 **재고 고른다.** 측정 전에 기본을 정하지 않는다.
2. 프로필 만들기 → 눈가림 3역할 채점으로 **기준선** 확보.
3. 축을 하나씩 사전등록으로 판정: `pop_boost` → `tag_w` → `strategy` → `hub_lambda` → `star_boost`.

**한 번에 하나만 옮긴다. 관측 후 문턱을 바꾸지 않는다. 점수를 위해 프로필을 조정하지 않는다.**

## 4. 쓰는 법

```bash
cd recommendation/webtoon
PYTHONPATH=. python -m src.crawl_naverwebtoon --out data/webtoons.jsonl --rps 2.5
PYTHONPATH=. python -m src.data_loader                 # 정제 → artifacts/wt_v1/dataset.parquet
PYTHONPATH=. python -m src.embed_qwen --rep v2         # 임베딩 (단독으로 돌린다)
PYTHONPATH=. python -m src.diagnose_representation     # 표현 진단 게이트
```

**메모리**: 임베딩은 백엔드·리랭커와 **같이 띄우지 않는다.** 과거에 그렇게 하다 cgroup 한계에서 죽었다.
