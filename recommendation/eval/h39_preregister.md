# 사전 등록 — 14차 배치

작성 시점: 13차(이중 게이트 회고 검증) 판정 직후, 14차 시드 생성 **이전**.

## 채택 (13차, Z1~Z4 전부 적중)
**이중 게이트: J >= 0.34 이고 유사도 순위 <= 5.**
72시드 회고: 적합률 79.2% → 86.1% [71, 94], 커버리지 74% → 50%.
동기 사례 1건 제외해도 Z1 유지(실패 중앙값 5.5 vs 성공 4.0).

## 확정된 설계 (누적)
1. 도메인마다 top-10 검색 (8차: top-3 병목, top-30 붕괴)
2. fun_tag 겹침 최대 후보 선택, 동점 시 유사도 상위 (9차)
3. J >= 0.34 이고 순위 <= 5 여야 칸을 얻음 (13차)
4. 통과 도메인이 칸을 나눠 가짐 — 전역 비율표 불필요
기대: 적합률 86%, 커버리지 50%.

## 문제 — 회고 검증의 한계
13차는 **이중 게이트를 이미 본 데이터로 판정**했다. 순위 컷 5는 h32 에서
데이터를 보기 전에 정했지만, 그 데이터가 6·7·9·10차를 포함한다.
**확정하려면 한 번도 쓰지 않은 시드에서 재현돼야 한다.**

## 예측 (14차 20시드, seed=2525, 후보 풀 top-10, 전부 신규)
- A1. 이중 게이트 적합률이 **75% 이상**이다 (72시드 86.1% 의 하한 근처).
- A2. 이중 게이트 적합률이 현행 게이트보다 **높거나 같다**.
- A3. 이중 게이트 커버리지가 **40% 이상**이다 (72시드 50%).
- A4. 현행 게이트 적합률이 **65~90%** 구간에 들어온다 (72시드 79.2%).

## 기각 조건
A1 또는 A2 가 빗나가면 이중 게이트 채택을 **철회**하고 현행 단일 게이트로 돌아간다.
A3 가 빗나가면 커버리지 대가가 감당 불가이므로 채택하지 않는다.
A4 가 빗나가면 79.2% 기준선 자체를 다시 의심한다.

## 남는 한계 (이번 배치로 해결되지 않음)
이중 게이트가 못 거르는 실패가 11건 중 4건 있다 — 전부 유사도 1~4위인데 부적합.
「용강표국」1위·「내 남편의 스캔들」1위·「무림 속 마법사」1위·「그라데이션 필터」4위.
순위로도 J 로도 안 걸리며, 14축 표현력 문제로 남는다.

## 프로토콜
3~11차와 동일 — fun_tag 를 파일에 먼저 확정한 뒤 등급을 매긴다.
등급은 현행/이중 두 게이트의 선택분 모두 매긴다(둘이 다를 수 있음).
