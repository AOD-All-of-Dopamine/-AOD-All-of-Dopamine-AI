# 사전 등록 h53 — 풀 수준. 프로필로 실제 검색했을 때도 성립하는가

작성 시점: h52 판정 봉인 직후(md5 `1ba0a74212a0bbc347af8f043c9361c3`),
**어떤 재검색도 실행하기 전.**

## 왜 이 배치인가

h48~h52 의 모든 결과는 **단일 웹소설 시드로 뽑은 10/10/10 균형 풀 안의 랭킹**이다.
실제 시스템은 프로필로 검색하고, 풀이 균형이라는 보장이 없다.
h52 의 W5 가 이미 경고했다 — 혼합 질의로 재검색하면 top-10 의 **55~74% 가 바뀐다.**

그래서 h52 의 W1·W2(쏠림은 인공물)는 **랭킹 수준에서만** 성립한 확증 대상이다.
이 배치는 그것을 **풀 수준에서** 다시 세운다.

그리고 아직 한 번도 묻지 않은 질문이 있다:
**프로필에 그 도메인 항목이 있으면 그 도메인 추천이 좋아지는가?**
이것이 크로스 플랫폼 추천의 실질이다. h51 에서 Steam 풀 적합률은 49.0% 로 가장 나빴는데,
프로필에 Steam 항목이 들어가면 Steam 풀이 개선되어야 한다.

## 설계

**시드는 h51 의 20개를 그대로 쓴다.** 재사용해도 결과가 새로 생기므로 누수가 아니다
(h49-B 가 h48 시드를 재사용한 것과 같다). 대신 **질의와 풀이 전부 새로 만들어진다.**

각 시드 s 에 대해 프로필 두 개 — h52 와 **동일한 구성 규칙**(임베딩 유사도, fun_tag 미사용,
시드 자신의 h50/h51 후보 제외):

- **혼합 M(s)** = { 웹소설 시드 s, Steam 항목, TMDB 항목 }
- **단일 S(s)** = { 웹소설 시드 s, 웹소설 항목, 웹소설 항목 }

**질의 = `top2_mean`**(확정 파이프라인). 허브니스 λ=0.35, 성인 필터, TMDB 한국어 제한 —
h50 과 동일. 각 도메인에서 **top-10** → 프로필당 30후보, 두 갈래 합쳐 시드당 최대 60후보.

**이미 라벨·채점된 항목은 그 값을 그대로 쓰고, 신규 항목만 라벨·채점한다.**
신규 건수는 검색 후에 보고한다. 채점은 눈가림, 3/2/1/0, 적합 = 2 이상.

## 예측

- **V1 (확증 · 핵심)** ft top-5 에 세 도메인이 모두 포함된 시드 수 M − S **≥ +6** (분모 20).
  → h52 의 W1(+8)이 **풀 수준에서 재현**되는지. 적중해야 '쏠림은 인공물' 을 **채택**한다.
  → 빗나가면 h52 의 W1·W2 를 **랭킹 수준 한정**으로 격하하고, 풀 수준에서는 쿼터가 필요하다고 본다.

- **V2** ft top-5 웹소설 칸 M − S **≤ −15** (분모 100). V1 과 방향이 어긋나면 해석 보류.

- **V3 (품질 비용)** ft top-5 적합률 M − S **≥ −5%p**.
  **h52 와 동일한 기준을 그대로 쓴다**(h52 는 −8%p 로 빗나갔다). 기준을 완화하지 않는다.
  → 빗나가면 교환비를 갱신해 명시한다.

- **V4 (크로스 플랫폼의 실질 · 신규)** **혼합 M 의 Steam 풀 적합률 − 단일 S 의 Steam 풀
  적합률 ≥ +10%p**, 그리고 TMDB 에서도 동일 기준 **≥ +10%p**.
  → 프로필에 그 도메인이 있으면 그 도메인 추천이 좋아지는가.
  → **둘 다 적중해야** "프로필 혼합이 각 도메인 검색 품질을 끌어올린다" 가 성립.
  → 빗나가면 프로필 혼합의 효과는 **랭킹 다양성뿐이고 검색 품질은 못 올린다**로 확정한다.

- **V5 (건전성)** 두 갈래 **모두**에서 ft top-5 적합률 − 무작위 top-5 적합률 **≥ +10%p**.
  → 빗나가면 그 갈래 무효, V1~V4 해석 금지.

- **V6 (기술 통계, 기각 조건 없음)** 갈래별·도메인별 풀 적합률, E 로 세웠을 때의 값,
  두 갈래 풀의 겹침 비율.

## 절차

- 라벨은 채점 **전**에 확정하고 md5 를 남긴다.
- 40조건(M 20 + S 20) 채점이 끝나기 전에는 어떤 집계도 계산하지 않는다.
- 임계값을 관측 결과에 맞춰 고치지 않는다. **V3 는 h52 기준을 그대로 유지한다.**
- 기존 라벨·등급은 재사용하되 **재라벨·재채점 금지**.
- 한계: 채점자 = 라벨러(D-6). 실유저 데이터 없음(D-3) — 프로필은 여전히 합성.

## h53 이 답하지 못하는 것

- **프로필 크기 축**(1·3·5). 이번엔 크기 3 으로 고정한다.
- **집계 규칙 축**(합집합 vs 교집합 vs 빈도상위k). 이번엔 fun_tag 합집합 고정.
- 게임·영화에서 **출발**하는 프로필. 시드의 웹소설 항목은 여전히 모든 프로필에 있다.
