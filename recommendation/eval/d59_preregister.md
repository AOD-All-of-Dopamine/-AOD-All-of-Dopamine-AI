# D-59 사전등록 — `mc_w` 가 들어온 뒤 `tag_w` 의 최적점이 올라갔는가

## 왜

D-58 로 채점 편향을 걷어낸 뒤 Steam 최하위 5개를 다시 보니 실패의 정체가 하나로 모인다:
**유명하고 평단 좋은데 태그가 안 맞는 것.**

```
coh_mmo (GW2/스론앤리버티/알비온)      → 위쳐3(g1) · Kingdom Come(g1) · 발더스게이트3(g1)  ← 전부 싱글 RPG
coh_sports (FIFA/매든/PGA)          → Men of War(g0) · Insurgency(g0) · PAYDAY 2(g0)
mix2_arcade_action (포르자/하이파이러시/SF6) → DOOM(g1) · 배트맨 아캄(g1) · HITMAN(g0)
mix2_coop_horror (리썰컴퍼니/파스모포비아/DRG) → 다크소울3(g0) · 엘든링(g0)
```

수치로도 같은 그림이다 (52프로필 top-50 슬롯):

| | tag_fit | quality | has_mc |
|---|---|---|---|
| 실패(g≤1) | **0.503** | **0.806** | 0.712 |
| 적합(g≥2) | **0.583** | 0.781 | 0.776 |

**실패는 태그가 덜 맞고 리뷰가 더 많다.** 최하위 5에서는 더 뚜렷하다 —
실패 tag_fit 0.471 / quality **0.837** / mc **0.750** vs 적합 0.585 / 0.777 / **0.617**.
**그 다섯 프로필에서는 mc 마저 실패 쪽이 높다.**

**근거가 있다.** D-49 가 `tag_w=0.40` 을 고를 때 **`mc_w` 는 없었다.** 격자는 0.20/0.40/0.60
이었고 **0.60 도 관문을 통과했으나 동점 규칙("작은 쪽")으로 0.40 이 뽑혔다.**
지금은 `mc_w=0.20` 이 보정항에 더해졌고 top-50 의 **77.8%** 가 metacritic 보유다.
보정 총량이 커진 만큼 **tag_fit 의 상대 비중이 줄었다.** 최적점이 올라갔을 수 있다.

**이것은 D-49 의 문턱을 옮기는 것이 아니다.** D-49 판정은 유효하고, 여기서 묻는 것은
**축이 하나 추가된 뒤의 새 질문**이다 (D-50→D-51 과 같은 구조).

## 먼저 기각된 가설도 적는다

**IDF 가중 태그 피복**(흔한 태그보다 희소한 태그를 무겁게)을 먼저 재봤다.
`tag_fit`·`quality`·`has_mc` 통제 후 잔차상관 **+0.029 (38/52)**,
"시드의 희소 태그 top3 적중"은 **+0.059 (37/52)**. `has_metacritic` 이 D-56 에서
보였던 +0.131 에 한참 못 미친다. **가설을 버렸고 사전등록하지 않는다.**

## 변경

`tag_w` 만 움직인다. `mc_w=0.20` · `quality_w=0.50` · `rec_boost=0.03` 고정.

    final = sim × (1 + rec·0.03 + quality·0.50 + tag_fit·**tag_w** + has_mc·0.20)

## 후보

`tag_w` = **0.60 · 0.80 · 1.00** (현행 0.40)

## 판정 기준 (관측 전 확정)

**dev 자격 (다섯 다):**
- **(A)** 전체 dev P@50 이 현행 대비 **+0.01 이상**
- **(B)** 저인기 축∩dev(7개, `lowrev_*`·`longtail_*`·`niche_*`) 평균 **−0.02 이상**
- **(C)** 어떤 dev 프로필도 **0.10 초과 하락 없음**
- **(E)** 전체 dev **ILS@50 이 +0.03 이내**
- **(F) 신설 — val 에서도 어떤 프로필도 0.10 초과 하락 없음.**
  **D-56 의 구멍을 메운다:** 그때 개별 관문을 dev 에만 걸어서 `twenty_broad` 가
  −0.28 나는 것을 아무것도 막지 못했다. 앞으로 개별 관문은 양쪽에 건다.

**자격자가 여럿이면 전체 dev P@50 이 가장 높은 것.** 동점(0.005 미만)이면
**0.40 에 가장 가까운 것** — 이유 없이 움직이지 않는다.

**val 확증:** 전체 val P@50 **+0.005 이상** · 저인기 축∩val(8개) **−0.02 이상** ·
ILS **+0.03 이내** · **개별 −0.10 초과 없음**.

**기각 시 `tag_w = 0.40` 유지. 문턱을 낮춰 다시 재지 않는다.**
