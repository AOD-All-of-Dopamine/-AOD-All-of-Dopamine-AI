# X-12 사전등록 — TMDB 랭커 `vote_w = 0.35` (D-60 재판정, 독립 3인 잣대)
## 근거 (관측됨)
독립 잣대 TMDB 338 슬롯(시드≥2), **프로필 내부 잔차** corr: 유사도 sim **+0.020** · 순위 −0.050 · 인기 백분위 **+0.253** · 평점 +0.211 · 장르 피복 +0.058 · 매체 0.
top-50 안에서 임베딩 유사도는 적합을 못 가르고, 인기가 가른다. D-60(vote_w) 은 은행 잣대 dev P@50 0.960 천장에서 +0.004 로 기각됐다 — 이 잣대의 TMDB 는 0.72 라 천장이 없다.
## 규칙
TMDB `PRODUCTION` 에 `vote_w = 0.35` (D-60 격자 {0.20, 0.35, 0.50} 의 중간값, 새로 조율하지 않는다). `vote_q = clip(log10(1+vc)/5, 0, 1)`, `base += vote_q × vote_w`. 통합은 M6 그대로.
X-11 과 다른 점: 하드 필터가 아니라 top-300 재정렬이다. 유사도가 비슷한 더 인기 있는 항목이 깊은 곳에서 올라온다.
## 대상·측정
60 프로필 전부 TMDB 목록을 vote_w=0.35 로 다시 만들어 M6 로 섞는다. (플랫폼, 항목) 집합이 달라진 프로필 = 영향군. 프로필당 10 슬롯(순위층 5×2, 시드 20260828015), 기존 채점 재사용, 신규만 3 역할 눈가림.
## 판정 (관측 전 고정)
주지표 **TMDB 슬롯 P** (영향군, 새 목록 vs M6 목록): (A) ≥ **+0.05** 채택 → TMDB PRODUCTION 갱신. (C) ≤ −0.05 기각. 사이 → 보류·미채택.
보조: 영향군 전체 P (Steam·웹소설 슬롯은 동일하므로 TMDB 차이의 1/3 으로 희석). 부작용: 새 TMDB 슬롯 중 투표 <500 비율, 롱테일 프로필(longtail_*, lowvote_*) 의 TMDB P 가 −0.10 넘게 떨어지면 기록.
## 예상
TMDB 슬롯 P 0.72 → 0.78~0.82 (+0.06~0.10). 영향군 전체 +0.02~0.03. 전체 P@50 0.820 → 0.83~0.84.
