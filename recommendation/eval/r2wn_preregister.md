# R-2wn 사전등록 — 웹소설 재표현: 규칙 태그를 임베딩 텍스트 앞머리에 넣는다
## 변경
`wn_v4` semantic_text = `제목 / 장르 / 줄거리`. **`wn_v5`** = `장르: G | 태그: t1..t5 \n 제목 \n 줄거리[:600]`. 태그는 `src/wn_tags.py` 의 규칙 사전(34개, 시놉시스·제목 어휘, 빈도 상위 5개)으로 붙인다 — 코퍼스 85% 에 1개 이상. 모델(Qwen3-Embedding-0.6B)·파이프라인·웹소설 PRODUCTION 값(pop_boost 0.03 등)은 그대로. **텍스트만 바뀐다.** 사전은 점수를 보고 조정하지 않는다.
## 측정
val = 페르소나 v2 32 중 웹소설 시드가 있는 26. 각 페르소나의 웹소설 top-50 을 v4/v5 로 각각 뽑고 M6 로 섞은 통합 목록에서 **웹소설 슬롯**만 본다: 통합 1-10 의 웹소설 슬롯 전수 + 11-50 의 웹소설 슬롯 표본(프로필당 5). v4 쪽은 X-15 채점 재사용, v5 쪽은 신규 슬롯만 3 역할 눈가림.
## 판정 (관측 전 고정)
(A) v5 웹소설 슬롯 P(11-50) − v4 ≥ **+0.05** 이고 웹소설 1-10 P 가 −0.02 이내 → 채택(`AOD_ARTIFACTS=artifacts/wn_v5`). (C) 1-10 이 −0.05 넘게 떨어지면 기각. 사이 → 보류, LLM 태그(변형 b)로 넘어간다.
보조: 웹소설 ILS@50(동어반복이 늘면 기록), 태그 0개 항목의 노출 비율.
## 예상
태그가 '결'을 헤더로 못박아 깊이에서 하위 장르가 유지될 것: 11-50 웹소설 슬롯 0.60 → 0.68~0.72 (+0.08~0.12). 1-10 은 ±0.02. 규칙 태그의 오매칭(15%)이 상한을 누른다.
