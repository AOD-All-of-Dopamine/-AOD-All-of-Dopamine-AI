# D-73 — 상태 점검. **깨진 것 하나, 갈라진 것 둘, 그리고 내 오진 하나**

실험이 아니라 **전수 점검**이다. 사용자 요청("지금까지 상태를 확인하고 분석해줘")에 따라
두 리포의 코드·설정·은행·서빙을 훑었다.

## 1. 깨져 있던 것 — 웹소설 `export_recommendations_md.py`

    ImportError: cannot import name 'REFRESH_REC_BOOST' from 'src.personalized_retrieve'

**모듈이 통째로 import 안 됐다.** 웹소설 리포는 Steam 에서 갈라져 나왔는데 상수 이름이
`REFRESH_POP_BOOST` 로 바뀌었고, 이 파일만 옛 이름을 그대로 부르고 있었다.
`REFRESH_POP_BOOST` 로 고쳤다. **이제 세 리포 전 모듈이 import 된다(0 깨짐).**

## 2. 갈라져 있던 것 — Steam 에도 `REFRESH_*` 상수가 있었다

D-66 에서 웹소설 `REFRESH_POP_BOOST = 0.15` 를 확정값 0.03 으로 맞췄다.
**그때 Steam 에 똑같은 상수가 있는지 확인하지 않았다. 있었다:**

| 위치 | 값 | 확정값 |
|---|---|---|
| `steam/src/personalized_retrieve.py:127` `REFRESH_REC_BOOST` | **0.15** | 0.03 |
| `steam/src/eval_product.py:216` `rec_boost` 기본값 | **0.15** | 0.03 |

둘 다 `PRODUCTION` 을 읽도록 고쳤다.

## 3. 그런데 이 갈라짐은 **행동에 영향이 없다** — 그리고 그게 더 중요한 발견이다

고치기 전에 실측했다. `rec_boost` 를 바꿔도 **52프로필 top-50 이 완전히 동일하다:**

    rec_boost  0.0 / 0.03 / 0.15 / 1.0 / **5.0**  → 기준(0.0)과 겹침 **50.0/50**

**원인은 D-39 가 기록한 백분위 결함이다.** `recommendations_total` 이 **87.4% 결측**이라
`fillna(0).rank(pct=True)` 가 그것들을 바닥에 눕히고, **리뷰가 있는 후보끼리는
top-20 백분위가 0.9976~0.9999 안에 뭉친다.** 폭 **0.002** 짜리 항은
`quality_w=0.50`(폭 ~0.5) 옆에서 순위를 못 바꾼다.

**⇒ `PRODUCTION["rec_boost"] = 0.03` 은 현재 코퍼스에서 아무 일도 하지 않는다.**
확정값 목록에 남아 있지만 실질은 **꺼진 축**이다. D-59 가 "Steam 보정항 세 개는 독립에
가깝다"고 한 것도 이 맥락에서 다시 읽어야 한다 — 셋 중 하나는 **아예 작동하지 않는다.**

## 4. 내 오진을 적는다

위 실측을 보고 나는 처음에 **"`rec_boost` 배선이 끊겼다"**고 판단했다. **틀렸다.**
`ranker.dataset` 의 인덱스가 실제로 `steam_appid` 이고(index.name 확인), 결과의
`recommendations_percentile` 은 정상값이다(top-20 중앙 0.9976, 0 인 것 0/20).
**끊긴 게 아니라 무력한 것이다.** 근거를 확인하기 전에 "끊겼다"고 말했다.

## 6. 열려 있는 것 (새 문제가 아니라 기록된 미결)

- **D-71 — Steam 채점 드리프트 +0.238.** Steam 절대 수치는 과소평가다.
  변형 비교(D-64·68·69)는 같은 은행이라 영향 없다. **D-72(재채점) 대기.**
- **D-25 — 사용자 등급 0줄.** 학습형 재정렬(+0.0204)이 여기 막혀 있다.
- **D-67 — 웹소설 `hub_lambda=0.50`.** 적합률 +0.0108 vs 10화 이하 +3.4%p 교환.
  사용자 판단 대기. k=50 미채점 0 이라 추가 채점 없이 즉시 재판정 가능.
- **`rec_boost` 무력(위 3번).** 실질적 개선을 원한다면 백분위 대신 **실측 리뷰 수**를
  쓰는 형태를 다시 봐야 하지만, D-39·D-40 이 그걸 이미 시험해 **둘 다 기각**했다.
  ⇒ **당장 열 축이 아니다. 다만 확정값 목록에 꺼진 축이 있다는 사실은 기록해 둔다.**
