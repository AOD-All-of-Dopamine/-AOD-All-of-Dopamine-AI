# 사전 등록 — 13차 배치

작성 시점: h36 가설 회고 기각 직후, 13차 시드 생성 **이전**.

## h36 기각 (배치를 뽑기 전에 기존 데이터로 판정)
"공유 태그 >= 2" 교정은 **무효**. J >= 0.34 와 구조적으로 같은 규칙이다.
J = s/(|A|+|B|-s) 에서 |A|,|B| ∈ {2,3} 이면 두 규칙이 완전히 일치한다.
갈리는 칸은 |A| 또는 |B| 가 1이거나 4일 때뿐인데, 관측된 시드 태그 개수는
2개 18건 · 3개 54건으로 그런 경우가 없다.
6·7차 24시드에서 두 게이트가 18/24 통과 · 15/18 적합으로 동일한 결과를 냈다.

**정정**: 「밀리어네어 레이디」실패를 "태그 2개라 J가 부풀려졌다"로 진단했으나
그 사례는 공유 태그가 2개였다. 개수 규칙으로도 통과한다. 진단이 틀렸다.

## 남은 진단
임계값·개수·풀 깊이 어느 것도 아니다.
**추상 축 2개 일치가 "같은 재미"를 보장하지 못한다**는 표현력 문제다.
[관계로맨스, 힐링평온] 은 로판 인생역전물과 생일파티 학원물에 모두 정직하게 붙는다.

## 이번 질문 — 축 체계 밖에서 보강할 수 있는가
게이트가 통과시킨 뒤 **유사도로 한 번 더 거르는 것**은 10차에서 W1~W4 전부
적중했으나 실패 표본 n=1 이라 보류했다. 지금은 누적 데이터로 실패 표본이 충분하다.
**새 배치 없이 6·7·9·10·11차 72시드로 회고 검증한다.**

## 예측 (기존 72시드, 새 시드 없음)
- Z1. 게이트 통과 후 실패(등급<2)한 건의 선택 순위 중앙값이 성공한 건보다 **높다**.
- Z2. "J >= 0.34 그리고 선택 순위 <= 5" 이중 게이트의 적합률이 현행보다 **5%p 이상 높다**.
- Z3. 이중 게이트의 커버리지가 전체 시드의 **50% 이상**이다.
- Z4. 실패 표본이 **8건 이상**이다 (10차의 n=1 문제가 해소됐는지 확인).

## 기각 조건
Z4 가 빗나가면 여전히 판정 불가이므로 새 배치를 뽑는다.
Z1 이 빗나가면 "실패는 뒤쪽 순위에서 온다"가 틀린 것이므로 이중 게이트를 폐기한다.
Z2 가 빗나가면 유사도 보강의 이득이 없는 것이다.
Z3 가 빗나가면 품질을 커버리지로 산 것뿐이다.

**순위 컷 5는 h32 에서 이미 등록한 값을 그대로 쓴다. 이번에 다시 고르지 않는다.**

## 주의

포함한다. 그 1건을 빼고도 결론이 유지되는지 함께 본다.
