# 사전 등록 h65 — 계측기 연구: 어떤 지표가 신호를 잡아내는가

작성 시점: h64 판정 봉인 직후(`9ec9d9db82404d708f2b1259a174d85f`), **어떤 지표도 계산하기 전.**

## 0. 왜 이것인가 — h64 가 계측기의 한계를 드러냈다

h64 의 음성 대조에서 나온 값:

> 등급을 **뒤섞은** 대조에서 M1−M0 = **+0.000 인데 승 5/10**.
> ⇒ 상위 3건 평균 지표는 **시드당 ±0.33 수준으로 흔들린다.**

그런데 h63·h64 가 쓴 **효과 기준은 +0.30** 이었다.

> **기준이 잡음 바닥과 같다.** 이 계측기로는 진짜 +0.30 짜리 효과도 절반은 놓친다.

h62·h63·h64 세 배치가 전부 "빗나감"이었는데, 그것이 **효과가 없어서인지
계측기가 못 봐서인지 구분할 수 없다.** 이건 앞으로의 모든 배치가 걸려 있는 문제다.

## 1. 물어야 할 것

**같은 데이터에서, 어떤 지표가 알려진 신호를 가장 확실하게 잡아내는가?**

이건 추천기에 대한 가설이 아니라 **계측기에 대한 가설**이다.
따라서 판정 구조도 다르다 — 승패가 아니라 **신호대잡음비(SNR)로 지표를 고른다.**

## 2. 골대 옮기기를 막는 장치

지표를 바꾸는 일은 **골대를 옮기는 것처럼 보일 수 있다.** 그래서 세 가지를 못 박는다.

1. **선택 규칙을 지금 확정한다** — 관측 후에 고르지 않는다(§5).
2. **선택 근거는 "내 가설이 이기는가"가 아니라 "알려진 신호를 잡는가"다.**
   양성 대조는 **코사인 vs 무작위**다. 이건 이미 확립된 사실이고
   (h63: 코사인 상관 0.590 · 쌍 단위 정확도 73.3%), 내 미검증 가설과 무관하다.
3. **과거 판정을 새 지표로 다시 계산해 뒤집지 않는다.** h62~h64 의 판정은
   **그대로 둔다.** 새 지표는 **h66 이후에만** 1차 기준으로 쓴다.
   (기술 통계로 병기하는 것은 허용하되, 판정을 바꾸지 않는다.)

## 3. 데이터 — 신규 채점 0건

h62 의 시드 10개 · 시드당 채점된 후보 24건 · 봉인된 등급 2,635쌍.
후보 1건의 실제 품질 = 프로필 3항목 대비 등급 3개(자기쌍 제외 시 2개).

## 4. 비교할 지표 — 지금 고정한다

| 코드 | 지표 | 비고 |
|---|---|---|
| **A** | 상위 **3**건의 실제 최고등급 평균 | **현행** (h63·h64) |
| **B** | 상위 **5**건의 실제 최고등급 평균 | k 를 늘린다 |
| **C** | 상위 **10**건의 실제 최고등급 평균 | 더 늘린다 |
| **D** | **NDCG@5** (이득 = 최고등급, 로그 할인) | 순위 정보를 쓴다 |
| **E** | 상위 3건의 **`적합_전체` 통과율** | 포화가 덜한 기준(D-17 대상) |
| **F** | 24건 전체에 대한 **스피어만 순위 상관** | 절단 없이 전부 쓴다 |

여섯 개 외에는 계산하지 않는다. 나중에 추가하지 않는다.

## 5. 선택 규칙 — 지금 확정

각 지표에 대해:

- **음성 대조**: 무작위 점수를 **2,000회** 추첨한다(D-16 준수).
  시드 10개 평균값의 **표준편차** = **잡음 바닥 σ**.
- **양성 대조**: **코사인** 점수. 시드 10개 평균값 = **관측치**.
- **SNR** = ( 코사인 평균 − 무작위 평균 ) / σ

**최고 SNR 을 가진 지표를 채택한다.**
동률(SNR 차이 0.2 이내)이면 **더 단순한 것**을 고른다 — 순서는 **A → B → E → D → C → F**
(작은 k, 이미 쓰던 것, 해석이 쉬운 것 우선).

**채택된 지표의 새 효과 기준 = 2σ** 로 정한다. 관측 후에 조정하지 않는다.
(2σ 는 "잡음의 두 배" 라는 구조적 경계이며, 지표별 값은 계산 결과가 정한다.)

## 6. 예측

- **L1 (1차)** 현행 지표 **A** 가 **최고 SNR 이 아니다.**
  - **적중** ⇒ 더 나은 계측기가 있었고, h62~h64 의 "빗나감"에 계측기 몫이 있을 수 있다.
  - **빗나감** ⇒ A 가 최선이었다. 세 배치의 결론은 계측기 탓이 아니다.
    **이쪽도 유용한 결과다** — 기각들이 더 단단해진다.

- **L2 (진단 · 기각 조건 없음)** 각 지표의 σ 와 SNR 표. h63·h64 가 쓴 **+0.30 기준이
  A 의 몇 σ 였는지** 역산해 보고한다.

- **L3 (건전성 검사 · 필수)** 코사인이 무작위를 **모든 지표에서** 이겨야 한다.
  어느 지표에서든 코사인이 무작위 이하라면 **그 지표는 고장 났거나 구현이 틀렸다.**
  발견 시 원인을 찾고 기록한다.

- **L4 (기술 통계)** 채택된 지표로 h62·h63·h64 의 대비를 **다시 계산해 병기**한다.
  **판정은 바꾸지 않는다**(§2-3).

## 7. 한계

- 지표를 고르는 데 쓴 데이터(h62 시드 10개)와 앞으로 그 지표를 적용할 데이터가
  **겹칠 수 있다.** 계측기 선택에 쓴 시드는 **h66 이후 배치에서 새 시드로 갱신**할 것을 권고한다.
- 양성 대조가 **코사인 하나**뿐이다. 다른 종류의 신호에는 다른 지표가 나을 수 있다.
- 시드 10개 · 후보 24건이라는 규모 자체는 이 배치가 바꾸지 못한다.
  **σ 가 크면 그건 지표 탓이 아니라 표본 탓일 수 있고, 그 경우 답은 시드를 늘리는 것이다.**
  그 진단도 L2 에서 나온다.
- 등급이 전부 내 것이다(D-6) · 실유저 없음(D-3).
