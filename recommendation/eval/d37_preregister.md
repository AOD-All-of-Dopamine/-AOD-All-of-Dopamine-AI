# D-37 사전등록 — Steam 랭킹에 품질 사전분포를 넣는다

## 진단 (관측 완료, 이 문서 작성 전)

Steam 52프로필 × k=50 = 0.4638. 프로필별 실패 원인을 전수 진단한 결과:

**추천 2,600개 중 1,324개(50.9%)가 리뷰 0개짜리이고, 그 구간 적합률이 0.271 이다.**

| 리뷰수 | 적합률 | 평균등급 | 쌍수 |
|---|---|---|---|
| 0 | 0.271 | 1.273 | 1,324 |
| 101~1k | 0.462 | 1.538 | 621 |
| 1k~10k | 0.815 | 2.119 | 411 |
| 10k+ | 0.922 | 2.578 | 244 |

- 프로필 **내부** 상관(log리뷰 vs 적합): 중앙 **+0.543**, 52개 중 **50개가 양수**, 43개가 ≥0.3
- metacritic 보유 항목 적합률 0.914 vs 미보유 0.407 (독립 신호)
- 프로필 **단위** 상관은 −0.021 로 씻겨 나간다 (심슨의 역설). 프로필마다 난이도가 달라서다.

즉 임베딩은 장르를 맞히고 있고, **장르가 맞는 무명 양산형을 걸러낼 축이 없다**(D-33).

## 왜 TMDB 의 D-31 해법(시드 상대 정합)을 쓰지 않는가

TMDB 는 `1 − align_w×|후보pct − 시드pct|` 로 고쳤다. Steam 에는 맞지 않는다.
저인기 취향 프로필(`lowrev_*` · `longtail_*`)에서도 리뷰가 많을수록 적합이 높다
(음의 상관은 52개 중 2개뿐이고 최대 크기 −0.116). 시드 상대로 묶으면
저인기 프로필이 더 좋은 항목에 닿는 것을 오히려 막는다. **절대 품질 축이 맞다.**

## 왜 백분위가 아니라 로그인가

기존 `rec_percentile` 은 랭커 docstring(2026-08-15)이 이미 결함으로 기록했다.
코퍼스의 87.4%가 리뷰 0 이라 동점 평균순위가 최하위에 0.437 을 준다.
리뷰 101개~520만개가 0.879~1.000 안에 다 들어간다. 해상도가 없다.
`log10(1+리뷰)/5` 는 동점 붕괴가 없고 단조다: 0→0.00 · 100→0.40 · 1만→0.80 · 10만→1.00.

## 변경

    final = sim × (1 + rec_pct×rec_boost + quality×quality_w)
    quality = clip(log10(1+recommendations_total)/5, 0, 1)

`rec_boost 0.03` 은 건드리지 않는다 (한 번에 하나만 옮긴다).
`quality_w = 0` 이 기본값이라 기존 실험은 그대로 재현된다.

## 절차

1. `quality_w ∈ {0.10, 0.25, 0.50, 1.00}` 를 **dev 32프로필에서만** 훑는다.
2. 네 설정이 만든 신규 쌍의 **합집합을 한 번에** 눈가림 채점한다.
   기준은 D-24 와 동일: `3=추천 가치 있음 · 2=장르 맞고 볼 만함 ·
   1=장르만 같은 무명/양산형 · 0=장르 불일치`.
3. **미채점 0** 에서 dev 비교. 아래 기준으로 하나를 고른다.
4. 고른 값을 **val 20프로필**에서 확증한다. val 도 미채점 0 을 맞춘다.

## 판정 기준 (관측 전에 고정)

**채택 조건 — 셋 다 만족해야 한다.**
- (A) dev 적합률이 기준선(quality_w=0) 대비 **+0.08 이상**
- (B) 어떤 프로필도 기준선 대비 **0.10 초과로 하락하지 않는다**
- (C) val 적합률이 기준선 대비 **+0.05 이상** (dev 상승폭의 60% 이상 이전)

**동률 처리.** (A)(B)를 만족하는 값이 여럿이면 **가장 작은 값**을 택한다 (D-21).

**기각 시.** 어느 값도 셋을 만족하지 못하면 `quality_w = 0` 을 유지하고
D-33 은 미해결로 남긴다. 문턱을 낮춰 다시 재지 않는다.

## 알고 있는 한계 — 순환성 (D-25)

채점 기준에 "무명" 이 명시돼 있고(1등급), 그 기준으로 만든 은행으로 평가한다.
따라서 리뷰수 사전분포가 점수를 올리는 것은 **부분적으로 동어반복이다.**
완전히 독립적인 방어는 아니지만 두 가지는 말할 수 있다:
- metacritic 보유 여부(리뷰수와 별개 신호)도 0.914 vs 0.407 로 같은 방향이다.
- 리뷰 0개인 Steam 항목은 대체로 미출시·방치·양산형이라 추천으로서 실물 가치가 없다.

이 한계를 감안해도 **50.9%가 리뷰 0 이라는 사실 자체가 제품 결함**이다.
val 확증(C)은 과적합은 막지만 채점자 편향은 막지 못한다. 그건 D-25 로 남는다.
