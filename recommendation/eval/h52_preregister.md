# 사전 등록 h52 — 혼합 프로필. 쏠림은 실재인가, 단일 도메인 시드의 인공물인가

작성 시점: h51 판정 봉인 직후(md5 `69a7b7b1a1e7c7e2f6ade25c4a83ca9a`),
**프로필 구성 및 어떤 집계도 계산하기 전.**

## 무엇이 막혀 있는가

h51 은 두 가지를 남겼다.
- 성립: 유사도로 도메인을 합치면 안 된다 · fun_tag 으로 합쳐라(92.0% vs 무작위 71.0%).
- **판단 불가**: 목록이 웹소설로 쏠린다(65/100칸, 세 도메인 모두 5/20) → 쿼터가 필요한가?

쏠림의 원인은 Z4(같은 도메인이 +31.2%p 더 잘 맞는다)인데, **h48~h51 의 프로필은
전부 웹소설 1개**였다. 프로필에 세 도메인이 다 들어 있으면 각 항목이 자기 도메인 후보를
끌어와 쏠림이 저절로 해소될 수 있다. 그러면 쿼터는 필요 없다.
**지금 데이터로는 이 두 가능성을 구분할 수 없다.**

(부수 확인: §2 "확정된 파이프라인"에 `프로필 집계 top2_mean` 이 적혀 있는데
h48~h51 네 배치는 시드가 1개라 집계를 쓰지 않았다. 원장 불일치이며 이 배치에서 정리한다.)

## 설계 — 신규 채점 0건

h51 은 시드마다 **10/10/10 으로 균형 잡힌 30후보**를 갖고 있고, 라벨(md5
`1155992ba39f71177f3c0f1c5a408e83`, `ad966719d46abcf162abed9a579632e4`)과 등급이
모두 봉인돼 있다. **쏠림은 풀이 아니라 랭킹에서 나온다**(풀은 이미 10/10/10 균형).
따라서 프로필만 바꿔 같은 30후보를 재순위하면 질문에 직접 답할 수 있다.

각 웹소설 시드 s(20개)에 대해 크기 3의 프로필 두 개를 만든다.

- **혼합 M(s)** = { 웹소설 시드 s, Steam 항목 x, TMDB 항목 y }
- **단일 S(s)** = { 웹소설 시드 s, 웹소설 항목 a, 웹소설 항목 b }

두 프로필은 **크기·집계가 동일**하고 **구성만 다르다.** 이것이 이 배치의 유일한 대조다.

### 구성 규칙 (fun_tag 과 독립 — 순환 차단)

x·y·a·b 는 **이미 라벨된 항목 풀**(h50 420 + h51 200 = 620건)에서
**임베딩 유사도가 시드 s 에 가장 높은 것**으로 고른다.
- **s 자신의 30후보는 제외한다** (자기가 평가할 항목을 프로필에 넣는 순환 차단).
- fun_tag 을 구성에 일절 쓰지 않는다. fun_tag 으로 묶고 fun_tag 으로 평가하면 순환이다.
- h51 에서 sim 은 랭킹에서 약했으므로(AUC 0.587) 유사도 기반 구성은 fun_tag 에
  유리하게 기울지 않는다. 오히려 보수적이다.

### 집계 규칙

- **임베딩**: `top2_mean` — 확정 파이프라인 복원. (W5 의 재검색에만 쓴다)
- **프로필 fun_tag**: 세 항목 태그의 **합집합**. 자유도가 없는 가장 단순한 규칙.

## 예측

- **W1 (핵심)** ft top-5 에 **세 도메인이 모두 포함된 시드 수**가
  혼합 M − 단일 S **≥ +6** (분모 20).
  → 적중하면 h51 의 쏠림은 **단일 도메인 프로필의 인공물**이고 **쿼터 불필요**.
  → 빗나가면 쏠림은 실재하며 **명시적 쿼터가 필요하다**로 확정한다.

- **W2 (쏠림 직접)** ft top-5 의 웹소설 칸 수(분모 100)가 혼합 M − 단일 S **≤ −15칸**.
  → W1 과 같은 현상을 다른 각도로 재는 것. 둘의 방향이 어긋나면 해석을 보류한다.

- **W3 (품질 비용)** ft top-5 적합률이 혼합 M − 단일 S **≥ −5%p**.
  → 빗나가면 혼합 프로필은 다양성을 사는 대신 품질을 잃는 것이므로 교환비를 명시한다.

- **W4 (건전성)** 두 조건 **모두**에서 ft top-5 적합률 − 무작위 top-5 적합률 **≥ +10%p**.
  → 빗나가면 그 조건 무효, W1~W3 해석 금지.

- **W5 (기술 통계, 기각 조건 없음)** 혼합 프로필 임베딩(`top2_mean`)으로 **재검색**했을 때
  단일 시드 검색 대비 바뀌는 후보 비율. 라벨·채점 불필요.
  → **풀 수준** 변화 크기를 재서 h53 의 필요성을 가늠한다.

## ⚠ 이것은 재분석이다

라벨과 등급은 봉인돼 있고 구성 규칙은 계산 전에 등록했지만, **h51 의 수치를
이미 봤다**(ft 세 도메인 5/20 등). h49-A 와 같은 지위다.
**W1 이 적중해도 '쿼터 불필요' 를 채택하지 않고 '확증 대상' 으로만 올린다.**
확증은 신규 시드 + 혼합 질의 재검색 + 신규 채점(h53)으로 한다.

## 절차

- 프로필을 구성하기 전에 이 문서의 md5 를 기록한다.
- 임계값을 관측 결과에 맞춰 고치지 않는다.
- h50·h51 의 라벨·등급을 **그대로** 쓴다. 재라벨·재채점 금지.

## h52 가 답하지 못하는 것

- **풀 수준 쏠림.** 이 배치는 10/10/10 로 고정된 풀 안에서의 **랭킹 쏠림**만 잰다.
  혼합 질의로 재검색하면 풀 자체가 달라지고, 그건 h53 이다(W5 로 크기만 가늠).
- 실유저 데이터가 없어 프로필은 여전히 합성이다(D-3).
- 시드의 웹소설 항목은 여전히 모든 프로필에 들어간다. 게임·영화에서 **출발하는**
  프로필은 별도 배치.
