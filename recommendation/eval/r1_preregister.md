# R-1 사전등록 — 크로스 인코더 리랭커로 Steam·TMDB top-100 을 재정렬 (2026-08-30)
## 대상
R-0 에서 51-100 적합률이 0.40~0.60 인 **Steam·TMDB**. 웹소설은 제외(후보 부재 → R-2wn).
## 방법
- 모델 `BAAI/bge-reranker-v2-m3` (CPU). 질의 = 플랫폼 시드들의 `semantic_text`, 문서 = 후보 `semantic_text`(앞 1,000자).
- 후보 = 플랫폼 랭커 top-100 (확정 설정·후처리 그대로). 점수 = 리랭커 점수 **단독**, 임베딩 점수와 섞지 않는다. 상위 50 을 새 top-50 으로.
- 시드 결합은 **두 변형 중 하나**를 dev 에서 고른다: (a) 시드 텍스트 이어붙여 질의 1개, (b) 시드별 질의 → 후보 점수는 시드별 최대. dev = 무작위 60 의 Steam·TMDB 슬롯(X-9/10/11 채점 재사용 + 신규), 지표 = 플랫폼 슬롯 P@50. **dev 에서 이긴 변형 하나만** val 로 간다.
- val = 페르소나 v2 32. 통합 M6 그대로(웹소설은 v4). 리랭크된 Steam·TMDB 목록으로 다시 섞은 뒤 1-10 전수 + 11-50 표본(프로필당 10)에서 **Steam·TMDB 슬롯**을 본다. 기존 채점 재사용, 신규만 3 역할.
## 판정 (관측 전 고정)
플랫폼별 독립 판정. (A) val 슬롯 P(11-50) − 현행 ≥ **+0.05** 이고 1-10 이 −0.02 이내 → 그 플랫폼에 리랭커 채택. (C) 1-10 이 −0.05 넘게 떨어지면 기각. 사이 → 보류.
부작용: 시드 속편·프랜차이즈 재유입(후처리 D-46·franchise cap 을 리랭크 뒤에 다시 건다), 대작 반복(ILS), 요청당 지연(100쌍 CPU 추론 시간 기록).
## 예상
TMDB: 11-50 슬롯 0.68 → 0.76~0.80 (+0.08~0.12) — R-0 에서 적합작이 깊이에 흩어져 있었다. Steam: 0.74 → 0.78~0.80 (+0.04~0.06). 1-10 은 둘 다 ±0.02. 변형 (b) 가 이길 것(시드 5개 취향이 넓을 때 최대가 안전).
