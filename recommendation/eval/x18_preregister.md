# X-18 사전등록 — TMDB 키워드 피복률(`kw_w`) (2026-08-31)

## 왜
TMDB 는 세 플랫폼 중 가장 약하다(통합 val 슬롯 P@50 0.78, 11-50 0.75). 정렬 보정항은 평점·장르피복·매체 셋뿐이고, 데이터셋의 `keywords`(중앙 5개)는 **임베딩 텍스트에만** 들어가고 정렬에는 쓰이지 않는다. Steam 은 같은 형태의 태그피복(`tag_w=0.40`)이 dev 0.793→0.835 를 만들었다.

## 사전 신호 측정 (p1 52프로필 은행 5,871쌍, 관측 완료 — 아래 판정과는 별개의 잣대)
장르피복 통제 후 잔차상관 / 프로필 부호일치:
`kw_cover` +0.078 (42/52) · `log_votes` +0.071 (33/52, 이미 2회 기각) · `yr_gap` +0.046 (29/52) · `same_decade` +0.035 · `n_kw` +0.034 · `ov_len` −0.001.
`kw_cover` 구간 단조: 0.856 / 0.873 / 0.923 / 0.963.
**연도·키워드수·줄거리길이·언어 축은 여기서 닫는다** (비단조 또는 부호 무작위). 이 사전등록은 `kw_cover` 하나만 다룬다.
주의: 이 은행은 설계자 채점이라 적합률 0.879 로 관대하다(D-25). **상대 비교·신호 선별에만** 쓰고 판정에는 쓰지 않는다.

## 변경
`tmdb/src/personalization/personalized_ranker.py` 에 장르피복과 **같은 형태**로 한 항 추가:
```
kw_cover = max_i |후보 keywords ∩ 시드_i keywords| / |시드_i keywords|      # 시드 개별 최대
base *= (1 + kw_w · kw_cover)
```
자카드는 쓰지 않는다(D-43 에서 죽은 형태이고 이번 측정에서도 +0.063 < +0.078). 시드 키워드가 비면 0. 다른 확정값(`rating_boost` 0.15 · `genre_w` 0.40 · `media_w` 0.20 · `hub_lambda` 0.35 · strategy mean)과 후처리는 **그대로**.

## dev — 계수 선택
p1 52프로필, k=50, 은행 채점(관대하지만 변형 간 **상대** 비교는 유효). 격자 **kw_w ∈ {0.2, 0.4, 0.6}**, 기준선 kw_w=0.
선택 규칙: 미채점 0 을 채운 뒤 52프로필 평균 적합률이 가장 높은 값 하나. 동률이면 작은 값. **격자 밖 값은 쓰지 않는다.**

## val — 판정 (관측 전 고정)
페르소나 v2 32 중 TMDB 시드가 있는 전부. 통합 M6 그대로(다른 플랫폼·웹소설 v4 불변), TMDB 만 새 계수로 재생성.
1-10 전수 + 11-50 표본(프로필당 10)에서 **TMDB 슬롯만** 본다. 기존 채점 재사용, 신규만 독립 3역할 눈가림 다수결.
- **(A) 채택**: TMDB 슬롯 P(11-50) − 현행 ≥ **+0.05** 이고 P(1-10) 이 −0.02 이내.
- **(C) 기각**: P(1-10) 이 −0.05 넘게 하락, 또는 P(11-50) 변화가 −0.02 이하.
- 사이 → 보류(현행 유지). 문턱은 관측 후 옮기지 않는다.
부작용 점검: 키워드가 많은 대작 쏠림(노출된 후보의 `n_keywords` 중앙 전후 비교), ILS@50.

## 예상
- dev 최적은 0.4. val TMDB 11-50 0.75 → 0.79~0.83 (+0.04~0.08) — Steam 태그피복(+0.04)과 같은 급이되 키워드가 장르보다 곱아서 조금 더 클 것.
- 1-10 은 ±0.02. 이미 장르피복이 상위를 잡고 있어 키워드가 뒤집을 여지가 적다.
- 실패 모드: TMDB 키워드는 결측·희소가 심하다(중앙 5개). 시드 키워드가 빈약한 프로필에서는 항이 0 이 되어 아무 일도 안 일어나고, 반대로 키워드가 많은 유명작이 분모 효과로 유리해질 수 있다 — `n_keywords` 중앙 이동으로 확인한다.
- log_votes 급(+0.07~0.09)의 신호가 독립 잣대에서 두 번 기각된 전례가 있으므로, **기각될 확률을 절반 이상으로 본다.**
