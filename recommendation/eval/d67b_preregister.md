# D-67b 사전등록 — 웹소설 `hub_lambda` 재판정. **사용자가 열었다**

D-67 은 사전등록 절차(2단계, k=20 승자 → k=50 확증)에서 승자 0.35 가 k=50 (A) 미달로 기각됐다.
0.50 은 k=50 에서 +0.0108 로 (A) 를 넘었지만 "1단계 승자가 아니라서" 채택하지 않았고,
"마지막 시도"라 적었으므로 재개는 사용자 몫이라 했다. **사용자가 열었다.**

## 달라진 것
통합 층 M3 가 웹소설 **화수 < 20 을 거른다.** D-67 의 대가("10화 이하 27.7% → 31.1%")는
통합에서는 **필터가 먹는다.** 그러면 남는 건 적합률 +0.0108 뿐이다 — 단일 플랫폼에서는
여전히 대가가 있으므로 **두 층을 따로 판정**한다.

## D-67 기각 때 적어 둔 재설계 그대로
1. **k=50 을 1단계로.** {0.0, 0.35, 0.50, 0.70} 이 k=50 에서 미채점 0 — 추가 채점 없이 즉시.
2. 동점 규칙은 판정 깊이(k=50)에서만.
3. **10화 이하 되돌림을 관문으로.**

## 판정 — 관측 전 고정

**단일 플랫폼 (웹소설 52 · k=50 · 미채점 0):**
- (A) 현행 0.0 대비 **+0.010 이상** · (C) 개별 −0.10 초과 없음 · (E) ILS +0.03 이내
- **(P) 10화 이하 비율이 현행 27.7% 대비 +2.0%p 초과 상승하면 탈락** — D-66 이 산 것을 되팔지 않는다.
- 자격자 여럿이면 최고, 0.005 미만 차이면 작은 λ.

**통합 (30 프로필 · M3 · k=10):**
- 자격자(위)를 웹소설 랭커에 넣고 M3 를 다시 돌린다. 새로 끌려온 웹소설 항목만 채점.
- **(X)** 통합 P@10 이 현행 0.893 대비 **−0.02 이상**(하락 허용치) · 웹소설 P 0.862 대비 −0.03 이상.
- 통합에서는 (P) 를 보지 않는다 — M3 가 이미 거른다.

**둘 다 통과해야 채택. 단일에서 (P) 탈락이면 통합을 보지 않고 기각** — 화수 필터는 통합 층
전용이고 단일 플랫폼 서빙(`next_page`)에는 없기 때문이다.

## 예상
D-67 데이터 그대로면 단일에서 **0.50 만 (A) 통과**(+0.0108). 문제는 (P) — D-67 에서
10화 이하 27.7 → 31.1 = **+3.4%p** 였으므로 **(P) 에서 탈락한다.** 즉 **기각 예상.**
그러면 "통합 층에 화수 필터가 있으니 단일 플랫폼 서빙에도 넣으면 되지 않나"가 다음 질문인데,
그건 D-62 가 관측 전에 잰 "화수는 플랫폼 내 신호가 아니다"와 정면충돌이라 별도 사전등록이다.
