# D-61 사전등록 — 세 가중치를 **동시에** 움직인다. 개별 최적점의 조합이 결합 최적점이 아니다

## 왜 — 세 가지 실측이 한 곳을 가리킨다

**1. 천장은 검색이 아니라 랭킹에 있다.**
채점된 후보 풀(프로필당 중앙 **136개**, 여러 변형의 top-50 누적)에서 등급 상위 50개를
고르면 **52프로필 전부 P@50 = 1.00** 이다. 최하위 `mix2_arcade_action`(현재 0.56)조차
자기 풀 안에 적합 후보가 50개 넘게 있다. **좋은 후보는 이미 들어와 있고 순서를 못 매긴다.**

**2. 같은 특징으로 학습하면 손으로 맞춘 가중치를 이긴다.**
같은 풀에서 프로필 단위 5겹 교차검증(누수 없음):

| | P@50 |
|---|---|
| 현행 수식·현행 가중치 | 0.8788 |
| **현행 곱셈형 · 가중치만 격자 탐색** | **0.8908 (+0.0120)** |
| 학습 가산형 (현행 4특징) | 0.8846 |
| 학습 가산형 + `rp`(리뷰 백분위) | 0.8919 |
| 학습 가산형 6특징 | **0.8992 (+0.0204)** |

**3. 격자가 고른 점이 개별 최적점과 다르다.**
`quality 0.75 · tag 1.2 · mc 0.4` (현행 `0.50 · 0.40 · 0.20`).

## 이것이 D-50·D-51·D-59 와 모순되지 않는 이유

세 판정은 모두 **한 번에 하나만** 움직였다.
- D-50/51: `quality_w` 를 양방향으로 → 0.50 이 최적
- D-59: `tag_w` 를 위로 → 0.40 유지 (최고 +0.0087, 문턱 미달)

**개별로는 각자 최적인데 함께 올리면 더 낫다면, 축이 상호작용한다는 뜻이다.**
"한 번에 하나만 옮긴다"는 규칙은 귀속을 깨끗하게 하려는 것이지 최적점을 찾는 규칙이 아니다.
**상호작용이 있으면 일변량 탐색은 원리상 결합 최적점을 못 찾는다.**

**단, 위 격자 수치는 낙관 편향이 있다.** 채점된 풀만 재정렬한 값이라 실제
파이프라인(300+ 검색 → 후처리 → top-50)에서 새로 들어올 **미채점 후보를 반영하지 못한다.**
그래서 여기서 확정하지 않고 **실제 파이프라인·미채점 0** 으로 다시 잰다.

## 변경

세 가중치를 **동시에** 움직인다. `rec_boost=0.03` · 후처리 고정. **수식 형태는 안 바꾼다.**

    final = sim × (1 + rec_pct·0.03 + quality·**qw** + tag_fit·**tw** + has_mc·**mw**)

## 후보 (5개, 격자가 가리킨 방향 + 중간점)

| | qw | tw | mw |
|---|---|---|---|
| **현행** | 0.50 | 0.40 | 0.20 |
| J1 | 0.60 | 0.80 | 0.30 |
| J2 | 0.75 | 1.20 | 0.40 |
| J3 | 0.75 | 0.80 | 0.20 |
| J4 | 0.50 | 1.20 | 0.40 |

J2 는 풀 격자의 최적점, J3·J4 는 어느 축이 이득을 내는지 가르는 대조군이다.

## 판정 기준 (관측 전 확정)

**(A) 문턱을 +0.015 로 둔다.** 풀 격자가 예고한 이득이 +0.0120 이고, 실제 파이프라인은
미채점 후보 때문에 그보다 **낮게** 나올 가능성이 크다. 그래도 낮추지 않는다 —
**낙관 편향이 있는 예고치에 문턱을 맞추면 안 된다.**

**dev 자격 (다섯 다):**
- **(A)** 전체 dev P@50 이 현행 대비 **+0.015 이상**
- **(B)** 저인기 축∩dev(7개) 평균 **−0.02 이상**
- **(C)** 어떤 dev 프로필도 **0.10 초과 하락 없음**
- **(E)** 전체 dev **ILS@50 이 +0.03 이내**
- **(F)** **val 에서도 어떤 프로필도 0.10 초과 하락 없음** (D-56 의 구멍. D-59·D-60 에 이어 유지)

**자격자가 여럿이면 전체 dev P@50 이 가장 높은 것.** 동점(0.005 미만)이면
**현행에서 가장 적게 움직인 것**(‖Δw‖ 최소).

**val 확증:** 전체 val P@50 **+0.005 이상** · 저인기∩val(8개) **−0.02 이상** ·
ILS **+0.03 이내** · **개별 −0.10 초과 없음**.

**기각 시 현행 유지.** 기각되면 **"일변량 최적점이 결합 최적점이기도 하다"** 가 답이고,
풀 격자의 +0.0120 은 **미채점 후보를 못 본 낙관 편향**이었던 것으로 기록한다.

## 예상 실패 모드

1. **(A) 미달 — 풀 격자의 +0.0120 이 실제 파이프라인에서 증발한다.**
   가중치를 올리면 검색 풀 깊은 곳에서 **아직 채점 안 된** 후보가 올라오는데,
   풀 격자는 그걸 못 봤다. D-59 에서 `tag_w=1.00` 이 실제로는 +0.0087 이었던 것과 같은 이유.
   **가장 가능성이 높다고 본다.**
2. **(C)/(F) 위반** — `tag_w` 를 1.2 까지 올리면 시드가 이질적인 프로필에서
   목록이 한 시드로 쏠린다(D-59 에서 이미 우려한 모드).
3. **(B) 위반** — `quality_w`·`mc_w` 를 함께 올리면 저인기 축이 밀린다.
   D-51·D-56 에서 각각 안 일어났지만 **함께 올리는 건 처음**이다.
4. 통과하면 **"축이 상호작용한다"**가 실증되고, 앞으로 일변량 탐색만으로 최적점을
   주장하지 않게 된다.

## 미채점 처리

다섯 후보의 top-50 합집합을 D-48 대로 섞어 눈가림 채점한다(시드 전체 노출).
**미채점 0 전에는 (A)~(F) 를 보지 않는다.**

## 하지 않는 것 (명시)

- **학습 가산형(+0.0204)은 이번에 시험하지 않는다.** 수식 형태를 바꾸는 것은
  가중치를 옮기는 것과 다른 변경이고, **같은 등급으로 적합하고 같은 등급으로 평가하는
  구조라 D-25(채점자=제작자)가 증폭된다.** 가중치 이동이 먼저다.
- **신규 특징(`rp` 리뷰 백분위 · `ntag` 태그 개수)도 이번엔 넣지 않는다.** 한 번에 하나.
