# 사전 등록 — 10차 배치

작성 시점: 9차 채점 완료 직후, 10차 시드 생성 **이전**.

## 하향 조정 (9차 결과)
- top-10 적합률: 6·7차만 보면 77.8/88.9% 였으나 9차 55.6% 로 풀링 **74.1% [55, 87]**.
  두 반복 전 "확정"이라 쓴 것은 18시드 근거였다. 36시드 기준으로 다시 적는다.
- 8차 진단 정정: "깊은 순위에서 J 는 높은데 무관한 후보가 걸린다"를
  top-30 고유 문제로 읽었으나, 9차에서 top-10 안에서도 같은 실패가 났다.
  풀 깊이 문제가 아니라 **14축 자체의 해상도 문제**다.

## 확정 유지
- 동점 시 유사도 상위 선택 (V2 빗나감 → 현행 유지). 동점은 12시드 중 6건으로 흔하다.
- 풀 깊이 top-10 (8차에서 top-30 기각).

## 이번 질문
14축 해상도가 부족하다면, 가장 싼 보강은 **유사도를 게이트에 함께 쓰는 것**이다.
지금 게이트는 J >= 0.34 하나뿐이고 유사도는 후보 순서에만 쓴다.
실패 사례(Truth, 트리 오브 세이비어, 99 Fails)는 모두 J 는 높고 **유사도 순위는 낮았다**.

## 예측 (10차 12시드, seed=1919, 후보 풀 top-10)
- W1. 실패(등급<2)한 통과 시드의 선택 순위 중앙값이 성공한 시드보다 **높다**(더 뒤쪽).
- W2. "J >= 0.34 **그리고** 선택 순위 <= 5" 게이트의 적합률이
      현행 게이트보다 **높다**.
- W3. 그 이중 게이트의 커버리지가 **50% 이상**이다 (현행 75%에서 너무 깎이면 무의미).
- W4. 현행 게이트 적합률이 **60% 이상**이다 (9차 55.6%가 바닥이었는지 확인).

## 기각 조건
W1 이 빗나가면 "실패는 뒤쪽 순위에서 온다"가 틀린 것이므로 이중 게이트를 버린다.
W2 가 빗나가면 유사도 보강이 효과 없는 것이므로 14축 보강을 다른 데서 찾는다.
W3 가 빗나가면 이중 게이트는 품질을 커버리지로 사는 것뿐이므로 채택하지 않는다.

**주의: 순위 컷 5는 9차 데이터를 보고 고른 값이 아니다.
top-10 의 중간값이라는 이유만으로 정했다. 9차 실패 사례의 순위(7,8,9)를
피하도록 맞춘 것이 아님을 명시한다 — 그렇게 했다면 6이나 7로 잡았을 것이다.**

## 프로토콜
3~9차와 동일 — fun_tag 를 파일에 먼저 확정한 뒤 등급을 매긴다.
