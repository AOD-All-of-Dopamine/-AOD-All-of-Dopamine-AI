# X-20 사전등록 — 제품 경로(`next_page`) 검증 (2026-08-31)

## 왜
지금까지의 모든 P@k 는 **첫 페이지 함수**(Steam `run_multi` · 웹소설 `Engine.recommend`)에 대한 것이다. 실제 사용자가 보는 새로고침 화면은 `next_page()` 인데 **평가 하네스가 이 함수를 한 번도 부른 적이 없다.** `next_page` 는 첫 페이지 함수와 다른 설정으로 돈다.

관측 완료된 사전 사실(판정과 별개):
- 구조 무결성은 두 플랫폼 모두 깨끗 — 5페이지 50슬롯에서 페이지 간 중복 0 · 시드 재노출 0 · 길이 미달 0.
- 첫 페이지 함수와의 겹침: Steam 73% · 웹소설 63%. 즉 27~37% 가 다른 항목이다.
- **웹소설 `next_page` 는 `strategy="max"` 로 돈다. 확정값 `PRODUCTION["strategy"]` 는 `top2_mean` 이다.** Steam 은 일치(`top2_mean`). 이 갈라짐은 D-55 와 같은 종류(확정값 미적용)이고, Steam 문서가 `max` 를 해롭다고 기록한 값이다("시드 3개 중 하나만 닮아도 상위에 올린다", `coh_grand_strategy` P@10 0.60).
- 품질 곡선(리뷰·관심 수 중앙)은 두 경로가 페이지별로 거의 같다 — 즉 `seed_scaled_floor` 등 추가 장치가 눈에 띄는 품질 차이를 만들지 않는다.

## 설계 — 두 팔, 플랫폼별 독립

| 축 | A 팔 | B 팔 |
|---|---|---|
| **X-20a 웹소설** | `next_page(strategy="max")` — **현행 제품** | `next_page(strategy="top2_mean")` — 확정값 |
| **X-20b Steam** | `next_page(...)` — **현행 제품**(추가 장치 켬) | `run_multi` top-50 — 평가된 경로 |

- 페르소나 v2 중 해당 플랫폼 시드가 있는 앞 12명(파일 순서, 점수 보고 고르지 않음).
- 각 팔에서 페이지 1·3·5 를 **전수** 채점한다(페이지당 10슬롯). 2·4 는 비용 때문에 제외 — 관측 전에 정한다.
- 기존 채점 은행 재사용, 신규만 독립 3역할 눈가림 다수결.
- 그 외 모든 설정은 코드 기본값 그대로. 두 팔은 **한 축만** 다르다.

## 판정 (관측 전 고정)

**X-20a 웹소설 — `max` vs `top2_mean`**
- (A) `top2_mean` 이 3페이지 합산 적합률에서 `max` 보다 **≥ +0.02** → 제품 경로를 확정값으로 통일한다. (문턱이 낮은 이유: 새 축 채택이 아니라 **확정값 미적용 결함의 수정**이다. 같으면 확정값이 이긴다.)
- (C) `max` 가 `top2_mean` 보다 **≥ +0.05** → 웹소설 제품 경로가 옳고 `PRODUCTION["strategy"]` 를 재검토해야 한다(별도 사전등록).
- 사이 → 확정값(`top2_mean`)으로 통일하고 "차이 없음"으로 기록.

**X-20b Steam — 제품 경로 vs 평가 경로**
- (A) 제품 경로가 평가 경로 대비 3페이지 합산 **−0.02 이내** → **제품 경로 검증 완료**로 기록, 변경 없음.
- (C) 제품 경로가 **−0.05 넘게** 낮다 → 제품 경로 결함. 추가 장치(`seed_scaled_floor` · `drop_dead_mp` · `series_session_max` · `bucket_offset`)를 하나씩 재판정하는 별도 사전등록을 연다.
- 사이 → 보류, 기록만.

보조 관측(판정에 쓰지 않음): 페이지별 적합률 곡선, 페이지 1→5 하락폭, 리뷰·관심 수 중앙 곡선.

## 예상
- **웹소설**: `top2_mean` 이 `max` 보다 +0.03~+0.07 나을 것. Steam 에서 같은 비교가 k=10 +0.057 · k=20 +0.077 이었고, 웹소설 시드는 5개라 `max` 의 "하나만 닮아도" 문제가 더 크게 난다. 페이지가 깊을수록 격차가 벌어질 것.
- **Steam**: ±0.02 이내로 큰 차이 없을 것. 겹침이 73% 이고 품질 곡선이 거의 같다. 다만 `next_page` 의 `min_reviews` 하한이 저리뷰 시드 프로필에서 후보를 과하게 잘라 오히려 낮을 가능성도 본다.
- 두 플랫폼 모두 페이지 1→5 하락은 있을 것(첫 페이지 함수도 31,410 → 6,111 로 떨어진다). 문서에 적힌 "3페이지에서 41% 붕괴"는 `quality_w=0.50`(D-38) 도입 전 숫자라 지금은 재현되지 않을 것으로 본다.

## 기록할 부작용
`max` 는 시드 하나에 쏠린 목록을 만든다 — 팔별 `dominant_seed` 분포(한 시드가 목록의 몇 %를 차지하나)를 같이 잰다.
