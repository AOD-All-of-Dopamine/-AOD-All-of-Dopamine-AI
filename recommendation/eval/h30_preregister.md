# 사전 등록 — 9차 배치

작성 시점: 8차 채점 완료 직후, 9차 시드 생성 **이전**.

## 확정된 것
- 7차: 풀 top-3 → top-10 은 커버리지·품질을 동시에 올린다 (T1~T4 전부 적중).
- 8차: top-10 → top-30 은 커버리지만 올리고 품질을 무너뜨린다 (U2·U3 빗나감).
  → **운영 지점 top-10 확정.** 더 넓히지 않는다.

## 8차에서 본 실패 방식 (사후 관찰)
깊은 순위에서 "Jaccard 는 높은데 실제로는 무관"한 후보가 걸린다.
J=1.00 인 13위가 등급 1, J=0.67 인 14위가 등급 1.
14축이 후보 30개를 가르기엔 해상도가 부족하다는 뜻으로 보인다.

또 하나: J 동점일 때 유사도 순으로 앞선 것을 고르는 지금 방식이
「히든랭커 길들이기」에서 졌다 (2위 고블린 위크 등급 1 vs 10위 원정 길드).

두 관찰 다 n=1~2 다. 앞선 반복에서 이런 관찰에 설명을 붙였다가 두 번 기각당했다.
그래서 이번엔 **동점 처리 규칙 하나만** 예측으로 건다.

## 예측 (9차 12시드, seed=1717, 후보 풀 top-10)
- V1. J 동점이 발생하는 시드가 **12건 중 3건 이상**이다 (동점이 드물면 규칙을 논할 가치가 없다).
- V2. 동점 시드에서 "유사도 상위 선택"과 "유사도 하위 선택"의 적합률 차이가
      **유사도 하위 쪽이 낮지 않다** (지금 규칙이 최선이 아님을 보이려는 것).
- V3. top-10 통과 후 적합률이 **70% 이상**을 유지한다 (6·7차 재확인).

## 기각 조건
V1 이 빗나가면 동점 문제는 실재하지 않으므로 규칙을 바꾸지 않는다.
V2 가 빗나가면 지금의 유사도 동점 처리가 옳은 것이므로 그대로 둔다.
V3 가 빗나가면 top-10 운영 지점 자체를 다시 의심해야 한다.

## 프로토콜
3~8차와 동일 — fun_tag 를 파일에 먼저 확정한 뒤 등급을 매긴다.
8차처럼 게이트 선택만 채점하되, 동점 비교를 위해 동점 후보는 모두 채점한다.

## 8차 이탈 기록
사전 등록에는 12시드로 적었으나 라벨링 부담(시드당 30건)으로 6시드로 줄였다.
결과를 보고 고르지 않도록 RNG 순서상 앞 6건을 썼다. 신뢰구간이 그만큼 넓다.
