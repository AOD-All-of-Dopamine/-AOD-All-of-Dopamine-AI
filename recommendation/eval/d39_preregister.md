# D-39 사전등록 — 리뷰 데이터를 다시 받고 품질 축을 제대로 만든다

## 문제 (관측 완료, 이 문서 작성 전)

`dataset.parquet` 의 `recommendations_total` 은 쓸 수 없다.

1. **173,691개 중 151,799개(87.4%)가 결측이다. 0 이 아니라 미보고다.**
   `has_recommendations=False` 와 정확히 일치한다. 지금은 이걸 0 으로 눕혀
   최하위로 만든다 — RuneScape · Dungeons & Dragons Online 같은 정상 대작이 밀린다.
2. **값이 있는 것도 틀렸다.** Steam 리뷰 API 실측과 대조:

| 게임 | dataset | 실측 | 배율 |
|---|---|---|---|
| Warframe | 2,881 | **674,726** | 234배 |
| Neverwinter | 295 | **39,644** | 134배 |
| Counter-Strike 2 | — | **9,807,790** | — |
| RuneScape | 결측 | **27,157** | — |

Steam appdetails 의 `recommendations.total` 은 Valve 가 일관되게 채우지 않는 필드다.

## 받는 것

`store.steampowered.com/appreviews/{appid}` 의 `query_summary`:
`total_reviews` · `total_positive` · `total_negative` · `review_score`.
미출시작(coming_soon 50,596)은 제외 → **123,095개**.

**긍정/부정은 인기도와 별개의 축이다.** "무명이지만 좋은 것"과 "무명이고 나쁜 것"을
가를 수 있다 — 롱테일 취향 프로필에 필요한 신호다. 지금 데이터에는 없다.

## 후보 (셋만 본다 — 채점 비용을 묶기 위해)

현행: `quality = clip(log10(1+recommendations_total)/5, 0, 1)`, `quality_w = 0.50`

- **Q1 (양만 교체)**: `clip(log10(1+total_reviews)/5, 0, 1)`
  같은 함수형에 실측 데이터만 갈아 끼운다. 데이터 결함만의 효과를 분리한다.
- **Q2 (윌슨 하한)**: 긍정 비율의 Wilson score 95% 하한.
  비율이 나쁘거나 표본이 적으면 낮아진다 — 양과 질을 한 항으로 합친다.
- **Q3 (양 × 감성)**: `Q1 × (0.5 + 0.5 × wilson)`.
  양을 주항으로 두고 감성으로 감쇠한다.

`quality_w = 0.50` 은 **고정한다.** 한 번에 하나만 옮긴다 (D-38 에서 정한 값).

## 절차

1. 세 후보 + 현행을 **dev 30프로필**에서 k=50 으로 돌린다.
2. 네 설정이 만든 신규 쌍의 **합집합을 한 번에** 눈가림 채점한다.
   기준은 D-24 와 동일: `3=추천 가치 있음 · 2=장르 맞고 볼 만함 ·
   1=장르만 같은 무명/양산형 · 0=장르 불일치`.
3. **미채점 0** 에서 dev 비교 → 하나 선택.
4. **val 22프로필**에서 확증. val 도 미채점 0.

## 판정 기준 (관측 전에 고정)

**dev 선택 (셋 다 만족해야 후보 자격):**
- (A) dev k=50 적합률이 현행 대비 **+0.03 이상**
- (B) 어떤 프로필도 현행 대비 **0.15 초과로 하락하지 않는다**
- (C) dev P@10 이 현행 대비 **하락하지 않는다** (−0.00 미만이면 탈락)

**자격을 갖춘 후보가 여럿이면 dev k=50 적합률이 가장 높은 것을 택한다.**
D-37 에서 "여럿이면 최솟값" 이라 잘못 쓴 것을 되풀이하지 않는다.
동점이면(차 0.005 미만) 더 단순한 쪽(Q1 > Q2 > Q3)을 택한다.

**val 확증:**
- (D) val k=50 적합률이 현행 대비 **+0.02 이상**

**기각 시.** 어느 후보도 (A)(B)(C)를 만족하지 못하면 현행을 유지한다.
문턱을 낮춰 다시 재지 않는다.

## 문턱을 왜 이 크기로 잡았나

D-37 은 축 자체가 없던 상태라 +0.08 을 요구했다. 지금은 이미 축이 있고
**데이터 품질만 바꾸는 것**이라 기대 효과가 작다. 미보고군은 top-50 의 13.8%까지
줄었고 그 구간을 완벽히 고쳐도 최대 여지가 +0.097 이다. 그 3분의 1 인 +0.03 을
의미 있는 최소치로 잡는다.

## 한계

순환성(D-25)은 그대로다 — 채점 기준 1등급이 "무명"을 포함한다.
다만 이번에는 **감성(긍정 비율)이라는 새 축**이 들어간다. 이건 "무명이냐"가 아니라
"좋으냐"를 보므로 순환성이 덜하다. Q2·Q3 가 Q1 을 이기면 그게 근거가 된다.
