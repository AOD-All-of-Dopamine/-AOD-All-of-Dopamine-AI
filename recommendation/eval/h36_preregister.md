# 사전 등록 — 12차 배치

작성 시점: 11차 채점 완료 직후, 12차 시드 생성 **이전**.

## 11차 처리
- X1 적중 (81.2%, 65~90% 안).
- X2 **빗나감** — 24시드로 늘렸으나 게이트 통과가 16건뿐이라 폭 36%p.
  게이트가 1/3을 버리므로 구간을 좁히려면 시드를 훨씬 더 늘려야 한다.
- X3 형식상 적중(50%p)이나 **채택하지 않는다**. 무협 n=2, 기타 n=2 가 만든 숫자다.
  셀이 2건이면 최대-최소는 거의 자동으로 커진다. 지표 설계가 나빴다.
  → 배치 변동의 원인은 **여전히 미결**. 장르로도 잡음으로도 결론 내지 않는다.

## 현재 상태 (6·7·9·10·11차 top-10 풀링 72시드)
통과 74% · 적합률 79.2% [67, 88]. 배치별 77.8 / 88.9 / 55.6 / 90.0 / 81.2%.

## 이번 질문 — 14축의 구조적 결함
11차 최악 사례: 「밀리어네어 레이디」[관계로맨스,힐링평온] →
「Come to my party!」[힐링평온,관계로맨스], **Jaccard 1.00, 등급 0**.
축이 2개뿐인 시드는 상대도 같은 2개를 가지면 1.00 이 된다.
즉 **J 는 태그 수가 적을수록 부풀려진다.**

가장 싼 교정은 **겹친 태그의 절대 개수**를 함께 요구하는 것이다.
(J >= 0.34 대신 "공유 태그 >= 2개")

## 예측 (12차 20시드, seed=2323, 후보 풀 top-10)
- Y1. 시드 태그가 2개인 경우의 적합률이 3개인 경우보다 **낮다**.
- Y2. "공유 태그 >= 2" 게이트의 적합률이 현행 J>=0.34 보다 **높다**.
- Y3. 그 게이트의 커버리지가 **50% 이상**이다 (현행 74%).
- Y4. 현행 게이트 적합률이 **65% 이상**을 유지한다.

## 기각 조건
Y1 이 빗나가면 "태그 수가 적으면 J 가 부풀려진다"가 틀린 것이므로 교정을 버린다.
Y2 가 빗나가면 절대 개수 요구가 효과 없는 것이다.
Y3 가 빗나가면 품질을 커버리지로 산 것뿐이므로 채택하지 않는다.

**주의: "공유 태그 >= 2" 는 11차 실패 사례를 보고 정한 값이 아니라,
Jaccard 가 부풀려지는 최소 조건(공유 1개)을 배제하는 유일한 정수 컷이다.
3 이상은 14축에서 너무 엄격해 커버리지가 붕괴한다.**
