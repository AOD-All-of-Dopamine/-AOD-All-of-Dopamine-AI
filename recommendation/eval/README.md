# 크로스도메인 추천 평가 — 원자료

`../EXPERIMENT_LOG.md` 가 **보고서**라면, 이 폴더는 그 보고서가 근거로 삼은 **원자료**다.
h16~h61 배치의 사전 등록문·판정문·라벨·채점·후보 풀·집계 스크립트가 들어 있다.

## 왜 커밋하는가

이 프로젝트는 **"결과를 보고 나서 예측을 고치지 않았다"** 는 규칙 위에 서 있고,
그 증거가 파일의 **md5 해시**다. `EXPERIMENT_LOG.md` 는 배치마다 md5 를 적어 두는데,
대조할 파일이 없으면 그 해시는 검증할 수 없는 문자열일 뿐이다.

원자료는 **재생성이 불가능하다.** 눈가림 채점 3,985쌍을 다시 매기면 값이 달라지고,
그러면 과거 판정이 전부 무효가 된다.

## 무엇이 들어 있나

| 패턴 | 내용 |
|---|---|
| `*_preregister.md` | 사전 등록문 — **데이터를 보기 전에** 쓰고 봉인 |
| `*_verdict.md` | 판정문 — 채점이 끝난 뒤에만 작성 |
| `*_addendum.md` | 보정문 — 집계 전에 절차를 고칠 때 (h58 만 존재) |
| `*_labels.py` | fun_tag 라벨 — **채점 전에** 확정 |
| `*_grades.py` | 눈가림 채점 (3/2/1/0) — 총 3,985쌍 |
| `*_key.json` · `*_grade_key.json` | ID ↔ 작품 매핑 (셔플된 정답 키) |
| `*_pools.json` | 배치별 프로필과 후보 풀 |
| `*_score.py` · `*_retrieve.py` · `*_mklabel.py` · `*_mkgrade.py` | 검색·생성·집계 스크립트 |
| `*seeds*.json` | 시드 목록과 사용 이력 (중복 추출 방지) |

## 무엇이 없나

- **채점 입력 청크**(`*.txt`, 143개 6.6MB) — `*_mkgrade.py` · `*_mklabel.py` 와
  `*_pools.json` 으로 재생성 가능하므로 제외했다. 단 코퍼스 아티팩트가 필요하다.
- **코퍼스 임베딩·데이터셋** — 각 도메인 `artifacts/` 에 있고 용량 때문에 gitignore 대상이다
  (Steam 173,691 · TMDB 59,780 · 웹소설 7,062).

## 검증하는 법

```sh
cd recommendation/eval && md5sum -c MD5SUMS.txt
```

개별 배치의 봉인값은 `../EXPERIMENT_LOG.md` 의 각 §8-x 머리말에 적혀 있다.
예: h61 등록 `352be0457d0e48a8543c87e6f58166b6` · 판정 `451721e397d5d2c5ff71908601838874`.

## 스크립트 실행에 관하여

스크립트 안의 경로는 작업 당시의 임시 디렉터리(`/tmp/.../scratchpad`)를 가리킨다.
**그대로는 실행되지 않는다** — 재현하려면 `SP` 변수를 이 폴더로 바꾸고,
코퍼스 아티팩트 경로를 환경에 맞게 조정해야 한다.
이 파일들은 **실행용이 아니라 기록용**으로 커밋한다.
